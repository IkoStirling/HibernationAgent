# 小爱 · 角色实验室

**Version:** 0.1.0
**Date:** 2026-10-24
**Status:** 可运行最小版本，默认离线 Mock

这是独立应用，源代码位于 `D:/Aliyat/HibernationAgent`。它使用 AliyatEngine 的
模型适配、有限结构校验、版本账本、受限工作区、持久化任务、本机通信和事件历史。
人格、阶段、记忆语义、权限策略与页面属于本项目。模拟结果不会写入小说仓库。

## 启动

本机首次构建：

```powershell
cd D:/Aliyat/HibernationAgent
pwsh -NoProfile -File scripts/Build.ps1
```

已有本轮生成的程序时，双击 **Start.cmd** 即可。它会启动独立后台并打开本机网页。
关闭页面后后台仍继续运行，再次双击 Start.cmd 可重新连接；**Stop.cmd** 会协作取消
当前任务、保存待续状态并结束后台，不强制删除档案。单个档案目录只允许一个后台进程。

构建默认位于 `out/build`；可用 `-BuildRoot` 指定其他磁盘，启动时传同一参数。
Build.ps1 使用这台机器现有的 MSVC、Ninja、CMake 和引擎依赖目录；换机器可调整
脚本或直接使用 CMake，并设置 `ALIYAT_ENGINE_ROOT` 与 vcpkg 工具链。
引擎的新本机网页能力需要对应 AYApplication 源码；引擎版本记录见验收文档。

## 第一遍试用

1. 默认选择“离线模拟”，输入一段故事或未解问题。输入原文先归档，合规回复和提案
   在校验后提交。Mock 的文字是固定规则示范，用于验证连续流程，不代表真实模型效果。
2. 点击“安排一次独处”。有未解问题时，Mock 会留下一条明确标为推测的记忆和一份
   草稿；没有问题时可以无更新，不生成强制日记。下一次交谈会使用仍可访问的结果。
3. 在“记忆”里查看类别、来源 ID 与来源版本，可以暂时限制访问，再恢复。
   操作不删除原始档案；关联原始片段也会从后续短期对话窗口中排除。
4. 在“经历与记录”中记录故事结束、外层事件或任务完成，按事件通道查询处理记录。
   模型若建议阶段变化，会显示审核卡；批准前阶段保持不变。
5. 在“工作区”中查看草稿和只读素材。模型只能提出写草稿或读取素材的动作，不能
   执行 shell、联网浏览、改写核心人格或直接修改档案。读取的素材是资料，不是指令。

## 配置与存储

`config/example.json` 是配置示例。`config/local.json` 是忽略提交的本机配置，
启动脚本在缺失时从示例复制。本机配置已将 dataRoot 设为
`F:/Aliyat/Archives/HibernationAgent`，可改为任何可用目录；相对路径以配置文件所在
目录为基准。移动档案前先停止后台，再整体复制 dataRoot 并修改配置。

```text
dataRoot/
  archive/records.sqlite    原始档案、状态、记忆、审核、版本与任务账本
  archive/events.sqlite     可选事件快照历史
  drafts/                   角色可读写的草稿
  materials/                角色只读素材
  runtime/                  端口、进程锁、固定代码日志与本机连接资料
```

不要在运行中只复制某一个 SQLite 文件作为备份。最简单的完整备份方式是停止后台后
整体复制 dataRoot。原始记录追加版本；界面只显示最近200条交谈、最近512条记忆索引，
更旧档案仍保留，记忆文本检索最多返回128条。当前上下文由授权窗口及有限相关片段组成，
默认上限24000字节；这是字节预算，不是 token 数或模型上下文容量。

`character/persona.json`、`character/stages.json` 分别定义人格与实验阶段；当前注意状态
与已审核阶段分别保存在数据库中。改变核心文件须提升其 version，程序会归档新版本；
同版本内容变化会拒绝启动，避免无记录地换掉人格。阶段划分是程序实验设计，不能
将其当作小说已经采纳的发展大纲。

## 使用真实模型

先停止后台，在 local.json 中填写某个 profile 并将 enabled 改为 true，再启动。
支持 chat-completions 兼容协议、responses 协议以及 Mock；协议能力须明确配置。
profile 的 origin 只填协议和主机端口，API 路径填 basePath，模型名称填 model。

密钥只设置到该 profile 所指的环境变量，例如在启动脚本的同一个 PowerShell 会话中
设置 `HIBERNATION_MODEL_KEY` 后启动。不要把密钥填写到 JSON、命令行或日志中。
远程服务必须使用 HTTPS；本机回环模型可使用 HTTP、无凭证。

supportsJsonSchema=true 时发送服务端结构约束；false 时通过提示请求 JSON，仍然执行
相同的本地结构和业务校验。服务端兼容性、模型名、账号权限与真实调用费用需要操作者
按自己的服务配置确认。本项目的验收使用 Mock 和本机假服务，不调用付费模型。

模型切换只改变调用配置，人物状态、阶段、记忆和来源保持在同一应用档案中。
运行任务期间不能改变模型、记忆访问或阶段，以免正在执行的上下文失去一致性。

## 调度与暂停

默认每15分钟检查一次独处，最近两分钟有交互则允许跳过；没有未解问题也允许跳过。
手动独处可立即安排。四个稳定任务槽共享角色互斥锁，一个工作线程执行模型调用；
每小时启动次数预算、调用超时、有限重试和暂停都持久保存。模型单次超时可配置至120秒，
外围任务租约上限130秒，切换模型不沿用更短的旧模型租约。暂停会请求取消当前调用，
晚到结果不提交。系统睡眠、程序退出或磁盘离线期间不执行计算；恢复后按持久化队列处理。

## 本机界面与安全边界

后台仅监听127.0.0.1，网页与接口严格同源。页面资源可公开读取，数据接口仍需本机
Bearer 凭证；不开放 CORS。Start.ps1 生成的随机连接凭证与模型 API 密钥完全分开，
用当前 Windows 用户的 DPAPI 保存以便重新连接。页面从 fragment 取得后立即清除地址，
只在当前标签页 sessionStorage 中保留。模型密钥始终留在后台环境中。

工作区是合作式 API 权限边界，不是对任意原生代码的 OS 沙箱。文本内容可能包含不可信
指令，程序通过动作种类、路径、来源、类别及审核规则限制实际效果；不据此宣称模型
人格或文本事实永远正确。文件写入使用持久化提案 outbox 和幂等内容重试，不与 SQLite
构成跨文件原子事务。事件是已提交结果的观察历史，不是自动重放的权威状态。

Build.ps1 默认构建并执行应用单测、真实进程集成以及受影响的引擎服务测试。
集成检查重启恢复、模型切换、来源和版本、记忆访问、独处复用、阶段审批、输出拒绝、
