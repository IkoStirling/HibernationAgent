# 小爱 · 桌面角色应用

**Version:** 0.7.0 · **Tag:** V0.7 · **Date:** 2026-10-27 · **Status:** Windows 本地可运行版本

仓库使用唯一的 `main` 分支。应用源码、插件、测试、脚本、界面、角色素材及便携工具均由 Git 管理；
`out/` 构建缓存、`artifacts/` 临时实验与诊断产物、本机配置、密钥和加密私人档案不进入版本库。

默认构建会校验并复制 `tools/runtime/` 与工具入口到构建目录的 `tools/`。
可以直接执行 `out/release/tools/bin/git.cmd --version`、`out/release/tools/bin/7z.cmd --help`，
或在 PowerShell 中执行 `. ./out/release/tools/UseTools.ps1`，仅为当前进程启用工具路径。
Git 支持本地仓库和常规远程操作（认证由用户配置）；7-Zip 支持 `.7z`、`.zip` 等格式的压缩、校验和解压。
工具不会自动初始化构建仓库、提交数据或赋予角色任意命令执行权。
如需手动管理构建产物，可使用其中的 Git 初始化独立仓库；应先排除本机配置、日志和私人数据。
使用 `-DHA_BUNDLE_RUNTIME_TOOLS=OFF` 可关闭复制。版本、来源和逐文件 SHA256 见
`tools/runtime/manifest.json`，验证命令为 `pwsh -NoProfile -File tools/VerifyRuntimeTools.ps1`。
保留上游发行文件和许可证；引擎资源导入、Cook、Pak、音视频等继续使用 AliyatEngine，
仅为引擎未提供的 Git 与通用压缩格式引入外部工具。

V0.7 封版后的持续开发重点是[人格连续性与自己的生活](docs/personality-development.md)：
在有来源的经历中形成兴趣和未完打算，允许重新理解、放下或无更新；感受渐变，
身体活动不会把心情重置。启用自主模式后，较早的小话题也有有限的独处考虑机会，
不要求每次记录心得或主动发言。旧关注在普通闲聊中退为背景，需要时可再找回。
核心人设与人工审核的发展阶段分别维护，实验成果不替换正式私人档案。

源代码位于 `D:/Aliyat/HibernationAgent`。程序复用 AliyatEngine 的模型适配、JSON
校验、版本账本、受限工作区、持久任务、事件通道、插件加载、完整视频播放与音频同步。角色协议、
记忆含义、权限策略、连续状态和界面由应用拥有；不改写小说正式设定。

首次使用可先看[简明使用说明](docs/使用说明.md)。

## 启动与日常使用

双击 **Start.cmd** 打开一个桌面对话窗口。关闭窗口会隐藏到系统托盘，后台继续运行。
托盘图标右键可打开对话、打开管理 Dashboard、暂停/恢复后台活动、保存退出。
**Stop.cmd** 也可安全停止后台，保留档案和待续任务。同一档案只允许一个后台进程。

全部插件关闭时，日常界面只有对话。记忆内容、工具调用、数值和内部记录不会放在
对话窗口或 Dashboard 中展示。角色可回复、拒绝或沉默；调用失败会独立显示，
不会拿网络错误冒充沉默。Enter 发送，Shift+Enter 换行，中文输入法选字不会误发。

默认使用离线 Mock，它是固定规则演示，验证保存与恢复流程。接入真实模型后，模型
才会自行选择工具、安排活动和形成回应。自动化验收使用本机合成模型服务。

管理页可从托盘打开，也可运行：

```powershell
pwsh -NoProfile -File scripts/Start.ps1 -Dashboard
```

`-NoBrowser` 为兼容旧测试保留，表示仅启动无桌面窗口的后台。已有这种后台时，
先 Stop，再正常 Start 才能使用桌面对话。关闭 Dashboard 不影响后台。

## 模型与密钥

“操作导师”是默认启用的可选求助插件：小爱在具体操作受阻时，可咨询本机已登录
ChatGPT 的 Codex，获取步骤建议，或把具体操作直接委托导师，由应用执行已授权
工具并返回逐步真实结果。直接执行可单独关闭。无需另填
导师 API Key；它不替换现有角色/审核模型。可在插件设置关闭，或选择暂不连接。
启用本身不调用模型，详情见 [插件说明](docs/plugins.md)。

在 Dashboard 的“模型连接”里设置协议、服务地址、接口前缀、模型名、超时和输出
限制，启用后保存，再选择为当前模型。支持 Chat Completions 兼容接口、Responses
接口、本机兼容服务和 Mock。服务地址只填 origin；接口路径单独填写。

“设置 API key”会先保存连接设置，再把密钥通过当前 Windows 用户的 DPAPI 加密
存到 `runtime/secrets/<连接ID>.dpapi`，后台载入对应进程环境变量。页面不回填密钥，
JSON、日志和命令行不保存明文密钥。也可自行在启动环境设置配置指定的变量。
密钥环境变量名不能覆盖 PATH、TEMP 等系统变量。远端模型要求 HTTPS；本机回环
服务可使用 HTTP 并留空密钥。连接能力和模型名称须按实际服务填写。

支持原生 JSON Schema、JSON 对象模式、旧式 max_tokens、画面理解均为显式选项。没有视觉能力时
不会向模型声称看懂画面。模型切换沿用同一角色档案，不重置人格、记忆或数值。
真实服务兼容性、画面理解效果和费用仍取决于用户选择的模型。
连接默认可读取 Windows 手动代理设置，也可指定无凭证 HTTP 代理；不执行 PAC/WPAD，
不修改系统设置，HTTPS 仍验证证书。

## 可选插件

在“可选插件”中分别启用并保存。插件是独立 DLL 与 manifest，可单独加载和卸载；
全部关闭不妨碍核心对话。管理页提供试用入口。

| 插件 | 已实现 | 具体边界 |
|---|---|---|
| 浮动电视 | 独立窗口、本地/直链视频播放与声音、播放/暂停/停止/跳转、实际画面截图、Internet Archive 视频搜索 | 本地文件限素材和草稿工作区；网页地址不等于媒体直链。支持视觉的模型可分析实际帧。未加入整部影片自动逐帧理解或语音转写 |
| 桌面小角色 | 三种可预览形象和三套配色、游走/好奇/休息/说话动画、鼠标点击与拖动、可选对白气泡 | 原创代码像素素材；动画是简单状态机。气泡和语音开始/结束事件联动，关闭插件可全部移除 |
| 文本转语音 | 可选系统中文棒读、Mei 中文假名合成音，或兼容 HTTP WAV 服务；自动朗读、停止、语速与最长时长 | Mei 将中文读音近似转为假名，并非原版 AquesTalk。HTTP 服务接受 model/input/voice/speed 并返回 WAV |
| 所在地天气 | 用户填写城市后查询 Open-Meteo，缓存/周期刷新，带来源的天气观测 | 不推测用户位置。天气缓慢影响心情、开放程度与精力变化速度；断网明确返回不可用 |
| 桌面小物 | 浆果、叶片、种子和纸星；角色接近、观察、食用、种植，芽苗按运行时间生长 | 需要桌面小角色。可关闭随机出现、自主接近和主动交谈；接受动作不等于完成，正在输入或有新对话时取消旧动作 |
| 安静节律 | 自主或模型选择短暂休息，实际确认姿态后计时，缓慢影响精力 | 需要桌面小角色，可关闭自动休息。输入或拖动可中断；暂停冻结，重启不补算离线休息 |

电视可以返回实际解码帧及来源 ID；模型可据此提出外层经历或推测记忆，再由程序
验证来源并保存。只有启用插件的工具会出现在模型可用能力中。原生插件是受信代码，
须使用相同编译器和运行库；工作区约束是模型工具边界，不是任意 DLL 的操作系统沙箱。

电视播放结束可交给角色处理，可在插件设置中关闭。待处理事件合并且两分钟后过期，
后台空闲时最多每20秒处理一次。点击和拖动即时改变动画；可在插件设置中开启
“拖动时使用预先准备的短反应”。空闲时批量生成并审核最多六条短句，静默合成语音，
实际拖动时消费一条就绪反应，用过即移除。空缓存、交谈/朗读期间或过期互动直接跳过，
不会排成延迟对白。鼠标当下不等待模型或审核连接。[实现与验收](docs/validation-conversation.md)。
天气刷新不会反复唤醒模型，语音事件也不会形成自我调用循环。

### 可选的 Mei 中文假名合成音

管理页 → 插件 → 声音，选择“声音类型：合成音”“音色：Mei · 中文假名（普通版）”。
`speed: 1.0` 对应普通试听版，`1.3` 表示在它的基础上加快30%；允许0.5至2倍，
音调固定为普通版，提高语速不会同时升调。此参数只影响 Mei，系统语音和 HTTP
服务保留原有 `rate` 设置。选音色、改语速、音量和朗读上限均可保存即时生效，
已开始的朗读使用其开始时的设置，下一次使用新设置。中文显示与角色上下文保持原文。

启用自动朗读时，新回复先等待语音合成，实际开始播放后才逐步显示。主对话窗口和
浮动气泡使用同一条回复的音频播放进度；气泡换页不会插入额外等待或打断语音。
Mei 在短句边界使用真实合成时长对齐，句内字符按读音长度估算，尚非逐字强制对齐。
其他未提供时间标记的语音按完整音频时长估算文字进度。无语音时仍使用原来的字符速度、
换页停留设置；合成失败或朗读被中断时，完整对白仍可在主窗口阅读。达到朗读上限时
声音会停止，剩余文字供阅读。旧交谈在重新打开应用后直接显示，不重新朗读。
播放进度仅在内存中维护，不作为记忆或外层经历存档。
模型的对白展示入口统一为最终 `reply.text` 与 `presentation`，角色工具目录不提供
`speech.speak`、`speech.stop` 或 `widget.say`；旧上下文仍提出这些调用时，程序明确拒绝并
引导返回最终对白，避免生成过程先发声、最终回复再朗读一次。管理页手动试听与停止
继续使用插件控制接口。

首次准备本地声库（额外包默认放 E 盘；需要 Python 3.12 x64 与 pip）：

```powershell
./scripts/PrepareSpeech.ps1 -PythonExecutable '你的 Python/python.exe'
```

可以用 `-RuntimeRoot` 指定依赖目录；`-BuildRoot` 应与实际应用构建目录一致。
准备后的 `plugins/tts/runtime.json` 保存本机 Python 和依赖路径，不含密钥，
不随源码分发；迁移电脑后重新准备。未安装时仍可使用系统音色和 HTTP 服务。
启动时使用 Mei，后台会预热并复用声库，避免每句话重新启动 Python 和加载字典。
长回复按标点分段，每段最多24字；首段就绪即开始同步显示和播放，后续段落提前合成。
合成中、缓存中和播放中的音频合计最多3段，使用同一个播放通道连续排队，
不等待整条回复合成完毕；停止或暂停会清空该次回复的待播缓存。
辅助进程由引擎 AYPlatform 托管，随插件退出；单次合成仍有超时和取消限制，
中断或故障后下次调用会重新启动。仅绑定本机回环地址，使用每个进程独有的随机凭据，
请求和 PCM 均在内存中传递；短暂的启动信息使用 Windows DPAPI 加密并在就绪后删除。
不把语音文件写入交谈档案。没有调用模型翻译或付费语音接口。
`speech.status` 中的 `last_synthesis_ms` 对 Mei 表示首段准备耗时，
`kana_worker_starts` 可检查声库进程是否复用，`maximum_buffered_segments` 表示缓存峰值，
`last_underruns` 记录当前/最近一句的缓存耗尽后续播次数。这些状态不会进入角色记忆。
分段开始时还不知道完整音频时长，`estimated_seconds` 只覆盖已准备部分，
`duration_complete:false` 明确标记此情况；文字进度使用各段实际音频时间标记。

Mei 声库由 MMDAgent Project Team / Nagoya Institute of Technology 提供，
遵循 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)，许可副本随准备脚本
保存为 `plugins/tts/LICENSE-Mei.txt`。使用 [Open JTalk](https://open-jtalk.sourceforge.net/)、
[pyopenjtalk-plus](https://github.com/tsukumijima/pyopenjtalk-plus) 和
[pypinyin](https://github.com/mozillazg/python-pinyin)。中文音节为近似映射，多音字使用
词组读音；数字逐位念，英文按字母念，罕见字与标点的精细调教仍有限。

## 加密存档与工作区

本机 `config/local.json` 使用 **E:/Aliyat/Archives/HibernationAgent**。F盘旧档案未迁移
或删除，当前不使用F盘。`config/example.json` 为可移植示例，路径相对配置文件解析。

```text
dataRoot/
  archive/records.sqlite     加密载荷：原始交谈、记忆、状态、任务、工具回执和来源
  archive/events.sqlite      仅事件索引与状态元数据，不存交谈正文或画面
  drafts/                    角色可读写的明文草稿（可另设目录）
  materials/                 角色只读的素材（可另设目录）
  runtime/memory-key.dpapi    当前 Windows 用户保护的记忆密钥
  runtime/secrets/            单独加密的模型/语音服务密钥
  runtime/                   端口、锁、连接资料与仅错误码日志
```

记忆文件载荷使用 ChaCha20-Poly1305，随机 nonce，并绑定记录身份、版本和来源。
原始档案与每次修订保留，遗忘只改变以后可访问的集合。缺失密钥、错密钥、损坏
或身份不匹配会拒绝读取，不自动创建空档案掩盖问题。旧明文账本首次打开会显式
迁移全部历史载荷并压缩数据库；不会删除原始版本。这里只保护静态记忆文件；
正常运行和已授权模型调用需要解密数据。不承诺对当前账户的进程调试进行隐藏。

停止后台后整体备份 dataRoot，必须连同记忆密钥一起保留；当前 DPAPI 方案绑定
Windows 用户，尚未提供跨账户导出密码或远端密钥管理。不要只复制运行中的单个
SQLite 文件作为完整备份。16TB设备可保存更多档案，不增加模型上下文或算力。

Dashboard 可修改草稿、素材目录，并防止它们与内部档案、核心设定或程序资源重叠。
程序配置文件与插件目录同样受保护，Windows路径比较不因大小写不同放过核心目录。
修改目录不自动搬运原文件。模拟结果不写入小说仓库。远端存储目前仅保存类型和
地址意向，**同步未实现、不会上传**，按此前约定延后。

## 协议、状态与独处

模型统一返回 turn-v1 JSON：回复、调用工具或沉默。应用进行结构和权限校验，逐个
返回成功/失败回执，模型再继续决定。原生 provider tool_calls 传输尚未接入；当前
采用兼容面更广的 JSON 文本协议；支持 JSON 对象模式的连接可显式发送 `json_object` 请求，仍通过本地结构校验和独立审核。不请求模型内部思维链，只处理显式回复与操作协议。
详见 [协议与错误处理](docs/turn-protocol.md)。

连续数值和活动状态独立管理：模型提出带来源的意图，程序按时间渐变，活动有最短
保持时间。状态定期保存，有明确意图时立即保存，正常退出保存。重启不把离线时长
直接换成情绪跳变。人格、发展阶段、当前数值分别管理，阶段候选须真实经历且人工
审核后才生效。阶段诊断/审核接口保留给开发调试，日常界面不展示内部记忆。

模型可自行安排至少一分钟后的单次活动或至少五分钟的周期活动、查询/取消自己
安排的任务。默认保留每15分钟一次的独处检查，近期交谈或没有问题时可跳过。
独处允许整理草稿、重审问题或完全无更新，不要求日记或主动发言。
互斥、实际模型调用预算、超时、有限重试与暂停均受程序控制。系统睡眠/关机时不运行。

后台独处期间仍可输入：新交谈会请求后台任务让位，过期候选不显示；已经完成的工具
回执继续保留。后台任务稍后以新上下文重试，自己的显式暂停不会被这一机制解除。
前台处理中仍只接受一个请求，重复请求身份返回原结果，不重做；全局暂停继续阻止输入。

管理页“模型连接 → 应用调用额度”可调整每小时模型调用数（默认600，范围1至1000）与操作阶段数（默认6）。角色、审核、格式修复和后台预生成共用本地调用额度；这不是服务商余额或官方限流。后台活动保留最后20%供用户交谈。用量与恢复时间直接显示；提高上限立即生效，重启不会清零已用次数。格式修复与审核改写另有界限，不占工具操作阶段；未通过校验或审核的内容仍不展示、不执行。

## 构建、测试与分发

本机已有构建可直接启动。重新构建需停止正在使用该可执行文件的后台：

```powershell
pwsh -NoProfile -File scripts/PrepareAudio.ps1
pwsh -NoProfile -File scripts/PrepareVideo.ps1
pwsh -NoProfile -File scripts/PrepareWebView.ps1
pwsh -NoProfile -File scripts/Build.ps1
```

日常运行可另建优化版本，保留开发检查目录：

```powershell
pwsh -NoProfile -File scripts/Build.ps1 -BuildRoot out/release -Configuration Release
```

调试默认为Debug；可选Release或RelWithDebInfo。已经配置的目录若显式传入不同构建
类型，Build/Test会拒绝，需先Configure或换独立目录，不会悄悄沿用旧类型。

PrepareVideo 只需首次准备：校验官方 FFmpeg8.1.2 源码头文件，并使用本机引擎已有
匹配 DLL 生成导入库。不会下载并替换整套引擎。Build 使用本机已有 MSVC、CMake、
Ninja 和引擎依赖目录，输出 `out/build`。换环境需调整路径或直接通过 CMake 配置。
`scripts/Build.ps1 -CoreOnly -BuildRoot out/core-only` 或 `HA_BUILD_PLUGINS=OFF`
可构建仅核心版本，不需要媒体 SDK。

默认检查应用单测、多轮协议/插件进程集成、旧流程兼容、启动器和引擎后台服务。
引擎改动另有存储、模型、插件、独立解码定向测试与 SDK doctor。
[设计](docs/design.md) · [插件开发](docs/plugins.md) · [来源与许可](docs/third-party.md)
· [本轮验收](docs/validation-desktop.md)。

本机生成的 FFmpeg/运行库尚不是对外发布安装包；跨机器分发需携带匹配依赖，核对

## 连续行为与媒体接入更新（2026-10-25）

角色的人格表达、当前关注和连续数值分别处理。精力、心情、注意力、开放程度、
交谈意愿与社交负荷缓慢变化，回复可以简短、拒绝或沉默；审核连接收到同一份状态，
不会仅因拒绝或沉默要求改写。阶段变化仍须经历依据与人工审核。

角色可通过 reflection.open/list/resolve 保存有来源的未解问题，并为相关问题安排
稍后的独处。任务持续保存来源，问题已关闭或来源撤回时跳过。思考结果仍是推测，
允许无更新，也不要求主动发言。检索包含较早记忆的关键词关联和任务明确来源，
当前并非语义向量检索。撤回访问会传递到依赖它的摘要和推测，原始记录依然保留。
程序记录重启间隔，不虚构离线经历，换模型也不重置状态。

浮动电视使用引擎 AYVideoPlayer + AYAudio 的解码线程、队列、播放控制和音频主时钟，

中的视频；任意磁盘路径仍不能播放。单轮限制视频搜索/打开/取帧次数，相同不可重试
失败复用回执，最后一轮留给回复或沉默。

三种语音均通过 AYAudio 输出。默认开启声音方向跟随小角色，可在管理页关闭；方向
按小角色所在显示器中心计算，50 毫秒内更新位置，不写入经历、不触发模型。隐藏或
卸载小角色后声音回到中央。语音缓存缺帧时保留文字进度，不再用空白播放时间推进。
语速倍率、分段预合成和三段缓存限制保持有效，不改变系统扬声器音量。

## 桌面工具与网页电视（2026-10-26）

小角色关闭后可从托盘右键“显示小角色”重新打开，管理页“插件”也有显示按钮。
当前能力、允许程序、目录范围及窗口状态每轮提供给角色，不必由用户先介绍工具。
首批电脑能力支持按清单启动程序、列授权目录和按需截图，由应用统一校验并提供
真实执行回执。“工作区”页配置程序和目录；整个屏幕观察默认关闭。

小电视支持按平台配置搜索页与内嵌网页，默认提供 B 站入口。用户在真实页面登录，
角色可观察实际文字、影片链接和画面；本地视频和直链继续使用引擎播放器。
网页桥接是初步功能，真实平台登录、验证码、自动播放和版权限制仍按网站行为。
小电视提供三种边框配色、原生播放/暂停与收起按钮，也可切回普通窗口。
[详细配置与限制](docs/desktop-tools.md)。

可选择的小角色形象、透明置顶启动标记与减少动画设置见[外观与启动表现](docs/appearance-and-startup.md)。
可选桌面物件插件提供食物、观察、种植与连续生长，见[桌面小物](docs/desk-world.md)。

精力相互对应；不需要持续发话。简单插件设置可以由清单声明并自动生成。

continuous_state 是实际连续状态；主对话和管理页不展示这些数值。
