# 应用边界与数据流

**Version:** 0.1.0
**Date:** 2026-10-24
**Status:** Active
**Owner:** HibernationAgent

## 1. 分层

引擎提供 LocalService、RecordStore、DurableQueue、WorkerHost、Inference、
Workspace 与 EventBus/EventJournal。本项目拥有角色设定、阶段、输出提案协议、
记忆类别、访问范围、草稿组织及页面。网页为有限静态资源，后台为独立 C++ 进程。
HTTP 工作线程通过有界 mailbox 交给唯一应用 owner；模型工作不在 HTTP 或 owner 上阻塞。

## 2. 一次输入

输入带稳定 request_id；先原子提交原文、最近索引和待处理请求，再放入持久化任务槽。
若在两步之间退出，启动恢复待处理请求；同一 request_id 不重复追加原文。
任务装配人格、当前阶段/状态、受授权原始片段和记忆，保留来源 ID/revision。
只请求可见回复、动作、记忆、状态及阶段提案，不请求内部思维链。
引擎校验完整返回，本项目再检查来源、类别、路径及发展依据。

成功结果通过 DurableQueue::finish 原子提交回复、记忆、状态、审核、trace、动作
outbox 以及任务完成；旧执行 token 或 revision 冲突不能发布部分业务结果。
无效提案整批拒绝，仅保留拒绝记录与诊断。网络错误有有限重试，预算计入任务启动。

## 3. 记录与访问

ha.archive 保存原文、外层/故事事件、回复和原始模型输出；ha.memory 保存程序采纳的
记忆提案；ha.trace 保存装配引用、配置快照及校验结果；ha.core 保存版本化人格和
阶段定义。ha.state、ha.stage、ha.access 分别管理当前状态、已审核发展阶段及可访问范围。
ha.index 是有限界面/候选索引，不代替永久档案。ha.requests 保存可恢复输入，
ha.actions 保存受限动作 outbox，ha.reviews 保存阶段建议及审核来源。
ay.queue.hibernation.* 是引擎的私有调度记录，角色不获访问权限。

推测和摘要不能提升为故事/外层事实。交谈、故事、外层类别须对应当前真实输入事件，
引用当前事件；所有引用须来自已装配授权内容或其明确来源。隐藏记忆时，后续装配排除
该条记录及它直接引用的原始片段，原始档案完整保留。此规则不是对语义推断的完整
信息流证明，也不保证其他可见材料绝不含相同内容。

## 4. 阶段与模型

人格和阶段定义是只读输入；同版本内容改变拒绝启动。模型只提议允许的下一阶段，
以多条不同且真实存在的经历作依据。批准时再次检查当前阶段和原始来源版本，再与
审核结论一并提交。模型切换沿用数据库中的状态/阶段/访问规则，按新 profile 调用，
不把模型自称当成角色身份迁移依据。结构连续性可验证，跨模型表现一致性需实际评估。

## 5. 独处与副作用

独处与交谈使用相同角色互斥锁。独处可以无更新，不追加强制日记或主动聊天消息；
有效构思以 inference/summary 等提案形式存储，可被之后的授权检索使用。
写草稿/读素材先成为数据库 outbox；owner 经 Workspace 校验后执行，再追加结果和
观察事件。同一写入可按相同内容重试。崩溃时待执行动作与未归档事件会继续收尾。
程序不提供 shell、任意路径、核心改写或正式小说发布动作。

## 6. 生命周期

后台对每个档案目录持有 OS 文件锁，避免重复宿主。关闭网页不停止后台。
关闭后台先停止接收请求，等待本机服务退出，再取消并收拢工作线程。队列、数据库、
事件连接和接收者按依赖顺序销毁。暂停、过期和重启仍采用引擎的至少一次与 fencing
语义；不声称任意外部副作用恰好一次。原始档案无删除 API。
