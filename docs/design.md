# 桌面角色应用：边界与数据流

**Version:**0.2.0 · **Date:**2026-10-27 · **Owner:**HibernationAgent

## 分层

引擎提供 JSON校验、RecordStore、受限工作区、持久队列/工作线程、本机服务、事件
通道、模型协议适配、加密原语、插件加载及视频播放和音频同步。应用负责角色语义、
来源权限、turn-v1、连续值/活动/发展阶段、审批策略、Win32对话与托盘。电视、
桌面角色、语音、天气、节律、小物、创作角、阅读和口袋玩具均可独立启停；连接类
插件沿各自授权边界运行。没有修改小说仓库或固定角色恋爱关系。

HTTP工作线程通过有界mailbox交给唯一应用owner；持久对话任务使用后台worker。
自主规划、短反应分别有批次生成器，同一主角色的这两类准备互斥，前台输入可抢占；
本地创作、阅读等耗时效果使用一个有界工作线程。原生控件/插件窗口由owner驱动。
主循环保持输入和动画，持久队列检查限10Hz，避免按每个动画帧反复扫描/解密存储。
后台关闭由协作取消与等待完成，不分离线程。

## 一次交谈

request_id确保输入幂等。先保存原文、最近索引与待办请求，再安排稳定任务槽；
重启补齐未排入的请求。当前人格/阶段/连续状态与获准原文、记忆按有限字节装配。
可用工具目录和统一协议交给模型。支持原生结构服务时，从工具参数生成闭合约束；
没有原生能力时请求JSON文本。都经本地校验与业务授权。

call轮次执行获准操作，先保存started、再保存completed回执，并反馈给模型。
原生操作以请求、工具参数和相同参数出现次序标识，服务商call ID另用于传输配对；
旧显式编号仍验证同编号完整参数。审核改写后重提相同已成功修改，复用原回执。
结果未知不盲重试。不同工具可分别成功/失败；这不是任意跨协议外部操作的通用事务。
工具已提交结果不会因后续最终回复失败回滚。最终reply/silence及旧提案桥的整批
结果由持久任务完成事务发布；过期执行token不能发布最终结果。

格式修复最多2次；默认模型轮次6次；总预算100秒，每次实际请求独立计入小时预算。
即时会话退避重试期间保留任务槽，独处的自动重试复用同一次发生的工具回执。
暂停取消当前工作、停止新任务，通知插件停止发声/播放/刷新/游走，并冻结连续推进。
已执行的外部效果不能声称因取消而撤销。恢复不重播历史语音和电影。

## 加密与记忆

当前新写入载荷使用引擎XChaCha20-Poly1305：HV2封装、24字节随机nonce、16字节认证
标签；32字节主密钥由Windows当前账户DPAPI保护，实际HV2密钥经域分离派生。
加密正文绑定记录身份、revision、schemaVersion、source、correlation、时间和载荷。
解密验证身份与认证标签，随机生成失败拒绝写入。旧HV1仅兼容读取，不重写旧记录；
历史算法和升级边界详见[记忆文件加密](encryption-v2.md)。

原始交谈、模型输出/回执、记忆修订、来源、调度和连续状态均在加密账本。
元数据索引仍可检索；事件历史只保存事件身份与执行状态，不保存交谈/画面正文。
草稿与用户主动放入的素材为工作区文件，与内部加密记忆分离。运行时解密数据和
正常模型请求可观察，不做反调试或抓包隐藏。

遗忘是访问集合的变化。检索前排除隐藏ID，关联原始来源也从短期上下文排除；
原始档案与修订不删除。读/写记忆须引用真实可用来源；故事事实、外层观测、推测、
摘要分别保存。来源带scope/id/revision/kind。更换模型不更换档案。

账本使用引擎私有格式2；载荷codec身份与账本格式不是同一个版本号。密钥缺失、
不匹配或认证失败拒绝读取，不创建空档案替换。停止后整体备份dataRoot并保留DPAPI
密钥。运行包回退不应覆盖新收到的消息或恢复较旧档案；涉及codec升级的回退规则
单独按匹配备份处理。尚未提供跨账户密码导出。

## 连续状态和阶段

RoleState统一持有精力、开放、心情、注意，以及当前/期望活动。有界意图建立目标，
按秒趋近，活动最短保持3秒，不按每条回复整块覆盖。天气刺激仅有有限幅度，
影响心情目标及开放/精力速度。模型给state.propose真实来源才能获准，意图立即保存。
数值/插件快照通常每30秒检查点，正常退出保存，重启不补算离线时间。

人格与阶段定义分别版本化，同版本内容改动拒绝启动。当前阶段和数值状态独立。
stage.propose提出下一阶段候选与不同真实经历，只进入pending；开发审核接口验证
来源版本并人工批准或拒绝。日常UI不显示记忆或数值管理器。

这些状态分别维护，不因模型更换合成一个巨大提示词：

| 层 | 模型能提出什么 | 程序维护什么 |
|---|---|---|
| 固定人格与阶段 | 提议有依据的下一阶段 | 原定义版本、经历门槛、人工批准 |
| 连续状态 | 有来源的活动/刺激意图 | 数值边界、目标、推进速度、暂停和重启时钟 |
| 个人关注self | 留下好奇、偏好、小意图，继续或放下 | 证据、同源去重、语义版本、缓慢趋近及完成依据 |
| 交流偏好 | 审核提取当前用户原文中的明确要求 | 原句核对、四次后续输入或二十分钟有效期 |
| 连续活动 | 一批最多六项命令及可选一句目的 | 权限、队列、有效期、实际完成/中断、并发及预算 |
| 记忆与观察 | 检索、记忆提案、获准回看原观察 | 分类、可访问性、来源版本、原始档案和投递事实 |
| 插件现场 | 使用当前工具，创造/摆放/读取实际对象 | 物件身份、容量、游戏规则、播放/动画与真实回执 |

self的渐变值、棋局胜负和物件程序属性不可用JSON直接赋值；有来源的个人感受仍可
自由表达。活动purpose不是思维链或完成证明。短期交流偏好也不改写人格、权限或阶段。

## 插件与工作区

清单决定已安装代码，配置决定启用能力。模型不能安装DLL或获得通用系统shell。
加载/重配失败回收暂存插件、尝试还原既有配置；启动失败保留核心和Dashboard。
启动故障按失败插件及其依赖隔离，不关闭无关工具；停用插件的旧快照保留但不作为
当前现场。具体工具与可用命令每轮提供给角色，关闭的插件不会由模型自行启用。
工作区还保护程序配置文件与插件目录；Windows目录比较使用不区分大小写的序数比较。
原生插件是受信代码，遵循相同ABI；权限约束面向模型工具，不声称原生恶意代码隔离。

电视复用实际FFmpeg解码，拥有式BGRA/PCM交给窗口和音频设备；WIC转换JPEG缩略帧
可作为视觉输入，文本模型明确收到无视觉能力。入口路径限制到素材根，内部协议/
格式列表防止播放列表转开本地文件或任意管道。不能把视频标题当完整观影经历。

桌面角色为透明全桌面窗口，角色活动范围以外透过鼠标。鼠标点击/拖动改变动画状态
并记录事件；对白气泡可与语音开始/结束时长联动。SAPI或HTTP WAV有界排队、取消
及最长时长，旧语音不恢复。天气只按用户城市查询，不推测地理位置。

## 配置和远端边界

Dashboard只提供运行、连接、工作区/存储意向、插件设置和试用，不浏览内部记忆。
模型/TTS密钥独立DPAPI文件，经指定进程环境变量供适配器取用，不回填页面或写入
明文配置。保留鉴权开发接口用于验收，不把界面隐藏当数据授权措施。
远端同步延后；仅保存类型/地址，enabled固定false，不发送存档。

## 验证

应用单测、独立进程协议/插件与重启检查、旧流程和启动器回归；引擎存储/加密/
模型/插件/解码定向测试；浏览器和原生实际交互检查。所有模拟数据使用独立验证
目录，生产档案不混入测试消息。实时第三方服务可用性和付费模型效果单独说明。

本轮增量说明见[2026-10-27更新](update-20261027.md)。原始观察、投递回执、近期访问
相关性分别处理：回看可以帮助后续接话，不能把旧画面标成现在新看到。缺少回执保留
不确定性，角色与审核接收同一批真正提供的图片。没有持续屏幕或麦克风输入。

后续重做记忆架构时，应保留工具语义、scope/id/revision/kind的可追溯身份、访问撤回、
原文持久保存和外部效果回执边界；内部索引可以替换，不必一并改动插件及身体状态机。
应用录音转文字和已验证的原生音频输入继续列为待做，当前不以TTS或播放成功代表听见。
