## 本轮追加的工作区UTF-8支持

原位置：`include/Hibernation/WorkspaceText.h` 把整段内容转成 JSON 并 dump，用序列化
失败来间接识别非法编码。它被工作区读写、搜索/编辑和 skill 文本接纳共同使用。

AYIO Workspace 是原始字节与路径/权限代理，已有公开依赖 AYString。SDK覆盖矩阵将
AYString列为 reviewed-internal 的实现支持模块；当前无独立UTF-8编码验证器。因此
本轮在 AYString 中增加 `Utf8.h`，不新建顶层模块或虚构独立玩法 capability。

应用继续先拒绝 NUL，再使用 `ayt::string::isValidUtf8`。通用函数自身接受合法的
U+0000，严格拒绝过长编码、代理区、截断、游离续字节及U+10FFFF以外的值；不转码、
不修复、不改写输入。它不代替业务文本许可、来源权限或长度预算。

AYString模块18个case/71断言通过，其中5类新UTF-8case。另用实际生产
WorkspaceText.h单独编译、运行消费端检查，确认合法文本通过、非法序列与NUL拒绝，
且不依赖JSON头文件。完整SDK再次0错误/0警告；应用候选的完整单元与原生工具两组
回归通过（49.18秒）。AYString子仓库提交为 `fb39b01`，引擎根记录及指针为 `d9d0f69`。

这是减少常规模型上下文负载的表示规则，不是权限沙箱：角色仍可通过已授权的
workspace.read分段读取自己的公开草稿JSON，不因此获得私有记忆或任意文件权限。

还确认编辑器按固定插件ID缓存文档会在工作区切换后保留旧预览；新工作区若存在同ID、
