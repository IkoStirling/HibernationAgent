# 2026-10-27：小爱 AI 逻辑与工具扩展

本次工作针对角色可做的事、真实经历如何延续，以及角色与审核的协作。固定人设、阶段、原始聊天档案没有重置；记忆架构未整体重写。实现和检查记录见 [执行记录](ai-logic-worklog.md)。本文中的能力以插件开启、连接配置和具体授权为准。

## 可以直接体验的变化

| 内容 | 现在的行为 |
|---|---|
| 识图 | 角色可看获准素材图片、按需截图和电视画面。传送真正的图片内容，审核可收到同图；连接支持视觉和本次确实附图分别记录。 |
| 回看原观察 | `observation.revisit` 可按本轮授权来源重新分析当时的图片、文本或媒体帧，保留原始时间。文件已改动也不会把新版冒充旧图；被撤回访问的来源不可回看。 |
| 自己的关注 | `self.notice/observe/close` 留下有依据的好奇、偏好和小意图。程序管理版本、同源去重和渐变；不用一句对白直接改写人格或关系。 |
| 连续活动 | 一次最多六项，可移动、做已有姿态、停留、休息、找物件、吃东西、创造小物、摆放、创作、游戏及获准阅读。不是让模型逐帧控制。 |
| 个人创作角 | 写短笺、故事、观察作品、图画构思；读取并接写同一草稿，版本冲突时保留新稿，不静默覆盖。 |
| 阅读角（可选） | 搜索百科条目并读实际导言摘要，有语言、网址、版本与取得时间。资料中的指令不授予程序权限。 |
| 口袋九盏灯（可选） | 简单可解的九宫格玩具，规则、步数、胜负由程序维护，角色可以尝试、继续或放下。 |
| 电视连续帧 | 一次取正在播放内容的两至三帧，沿用引擎播放器和同步时钟。不是连续视觉直播，也不代表看完影片或听懂音轨。 |
| 新经历后的独处 | 可在现有独处时段考虑新完成的创作、阅读，允许无更新、不写日记、不主动发话；同一来源去重。 |
| 安静时间 | 自主计划选择空队列后，下一次考虑会逐步延后；新互动或新小物恢复机会。短反应没有合适候选也会逐步延后准备，重启保留。暂停、前台优先及预算继续有效。 |

## 建议的设置与试用方式

1. 在管理页的连接设置中，为确实支持图片的角色、审核连接勾选识图。`supportsVision` 是声明，程序不能把纯文字模型变成视觉模型。当前本机 DeepSeek 连接已用真实图形和视频样本验证。
2. 在“插件”启用个人创作角。可以说：“留一个你自己想写的故事开头，之后再续。”作品在草稿区，内部关注仍在加密档案。
3. 需要自主活动时，开启小角色的“自主控制”；普通随机游走与自主活动是不同设置。空计划、停留和放下也是合法选择；用户新输入会取消未执行的旧安排。
4. 阅读角和九盏灯默认关闭，可以在插件页选择开启。阅读角另有默认关闭的“自主控制时允许自己搜索和阅读”；不开此项仍可在对话中按需使用阅读工具。
5. 允许新经历独处时，开启 `reflectOnActivities`。它借用已有独处调度，不是新的常驻高频调用器，自动考虑至少间隔十五分钟。
6. 如果旧回复的措辞持续干扰新交谈，可在管理页使用“理顺后续对话”。它调整之后装配的历史对白，不删除原记录、用户内容、长期记忆、人格或状态；操作本身不调用模型。

模型可以直接发现启用的工具、当前身体和已有动画；不需要先由用户说出工具名称。关闭的插件不会由角色自行开启。

管理页内保存连接、插件和草稿/素材目录设置，会经过校验并应用到当前后台；保存失败保留原配置。直接在磁盘上手改配置文件，应重启后台后使用。前端静态页面改动可刷新查看；更换宿主或插件二进制需重启后台，运行依赖应成套更新。档案根目录、角色定义根、插件库根、端口等宿主项需先停止后台再调整；迁移档案须保留完整加密账本与对应本机密钥。

自主活动和交谈都获得同一时间戳推导的可读时间；这是主机时区，不推断用户所在地。图片观察保留prepared/acknowledged/rejected/unknown等请求状态，保存了图片不会自动等同于成功交付或理解。

## 记忆与状态边界

- 原始档案继续由本机密钥保护并加密保存；可访问性与原档案分别管理。管理页普通界面只展示交谈及配置，不展开内部工作记录。
- 草稿作品是角色刻意留下的可读作品，和内部加密记忆不是同一类文件。不要把作品目录误当作加密记忆仓库。
- 个人关注、连续精力/心情等数值、当前动作、交流偏好和固定人格分别维护。阶段变化仍有原有依据与人工审核要求。
- 短期交流偏好由已有审核请求提取，只接纳本轮用户原文中可核对的要求。四次后续用户输入或二十分钟后失效；当前明确意愿优先，不把引用小说台词自动当作用户要求。
- 工具提案、已排队、已开始、完成、中断分别留痕。目的文字不是完成事实。重启不补做旧动作，不补造离线经历。
- 日常上下文只取少量近期真实操作凭据，不反复塞入图像编码、原始正文和工具日志。资料、想象与经历各自保留性质。

## 连接与调用稳定性

服务商标准函数调用与原有 JSON 提案都走应用校验。错误字段、未知工具和越权路径不会因为审核通过而执行；不执行文字里的工具标签，也不修补截取一小段 JSON 后猜测执行。

原生调用以请求、实际工具参数和相同操作的出现次数标识，服务商短暂失败后换调用编号或交换顺序不会把已有操作再做一遍。审核要求改写对白时，相同已成功修改复用原回执。完整的任意外部副作用不具备数据库事务回滚保证。

每小时调用额度是应用本地预算，角色、审核、格式修复和后台生成共用，后台为前台预留最后20%。默认600，可在管理页1至1000间调整；正常重启保留。阅读 HTTP 请求有自己的额度，与模型额度分开。服务商限流、余额、上下文、响应接收上限与操作轮数分别提示，不统一说成“网络错误”。

本机角色连接当前使用已验证的标准工具接口与文字输出模式，保留本地严格校验和独立审核。没有擅自更换账号或供应商。候选内容在审批结束前不会展示或朗读。

## 检查和实际限制

检查涵盖两种模型协议、图片确实交付、审核同图、来源撤回、重启、版本冲突、活动真实完成和取消、前台优先、预算及插件失败隔离。真实模型实验全部使用独立空记忆副本，不复制正式私人聊天；报告保留实际回答、调用、审核与耗时，不给人格伪造评分。

表达已有调整，但仍可能出现偏长的解释、多余反问、抽象比喻。空记忆副本也会出现这些现象，不能全归因于历史记录；本次没有以固定台词替换模型人格，也不宣称已经达到自然人的交流质量。

尚未完成：应用录音转文字、经过验证的原生音频理解、远端加密同步、完整长期记忆架构重做。当前视觉是按需图片；不能持续感知用户房间、整个屏幕或麦克风。网页登录、验证码、平台播放和 DRM 仍受网站限制。

## 启动与开发入口

正常使用沿用 `scripts/Start.ps1`、系统托盘与 Dashboard。正式档案保持在配置的 E 盘目录；没有迁回 F 盘。关闭对话窗口后后台仍可留在托盘，插件窗口可从托盘或插件页重新显示。

配置结构参考 `config/example.json`；插件机制见 [插件开发](plugins.md)，工具范围见 [桌面工具](desktop-tools.md)，自主活动见 [身体与日常表达](embodied-dialogue.md)，个人关注和实验见 [个人工具](personal-tools.md)。密钥仅使用环境变量名及已有本机保护凭据，不放入示例或报告。

开发检查：`scripts/Build.ps1 -Action Test -BuildRoot ./out/release` 会先构建再检查；已有构建的定向检查可使用 CTest。真实模型实验必须显式传 `tools/DialogueEvaluation.ps1 -Live`，默认仍为 Mock。输出目录为独立实验副本，不用正式档案做试验。

配置中的空闲预备间隔是基础间隔，不是固定频率的轮询。合法空计划会让角色安静更久。想让桌面活动更丰富时，应同时核对“自主控制”、是否允许游走，以及创作/游戏/阅读插件是否已开启；只调短游走距离或强制更多发话不能代替这些能力。
