# 像素序列帧角色

制作前先看[小爱动作与动画制作总表](character-action-catalog.md)，按现有动作、复用关系和待接场景选择素材；新增动作或替换素材后同步更新总表。

小组件默认改用 PNG 序列帧，支持单张 PNG 序列和规则/手工指定矩形的图集。
小恐龙、月羽鸟和微光三种内置形象各带一套可编辑资源，包含待机变体、行走、
拖拽、落地、接收消息、思考、进食、说话及睡眠的开始、循环和结束。
这些资源由现有原创像素图生成，没有使用 VPet 的角色素材或程序代码。

## 使用与配置

Dashboard → 可选插件 → 桌面小角色：

- **动画来源**：像素序列帧，或原来的内置简易动画。
- **自定义动画包目录**：留空使用所选内置形象；填写包含 `character.json` 的绝对目录，
  优先使用该自定义资源包。在“角色形象”中重新选择内置预设会清空此目录，避免旧路径继续覆盖选择。
- **动画图片缓存上限**：默认64 MiB，允许16至256 MiB。

保存插件设置即可重新加载，无需重启。修改磁盘素材后也通过保存重新加载；
当前没有实时文件监视器。爱丝特兰预设使用当前 PNG 素材的实际缩略预览，其他三种形象保留简易预览；未知外部包显示自定义提示，避免误展示其他形象。
默认跟随 Windows 的减少动态效果设置；关闭 `respectSystemMotion` 后，小组件可
独立播放动画，不改写 Windows 设置。应用自身的 `reducedMotion` 仍优先生效。
暂停冻结动画与移动；减少动态效果时显示各阶段的首帧，仍能切换姿态。
外部包默认保留图片原色；只有声明 `"palette": "builtin"` 的同色板素材才跟随内置配色。

## 最小资源包

把两张透明背景、32×32 的 PNG 和下列 `character.json` 放在同一个目录：

```json
{
  "version": 1,
  "id": "my-character",
  "canvas": [32, 32],
  "anchor": [16, 32],
  "hitbox": [5, 5, 28, 30],
  "states": {
    "idle": [{
      "id": "breathing",
      "loop": [
        {"image": "idle-01.png", "ms": 120},
        {"image": "idle-02.png", "ms": 180}
      ]
    }]
  },
  "fallbacks": {"listening": "idle"}
}
```

`idle` 必须存在；缺少其他动作时自动使用 idle。每个状态可有1至8个变体，
以 `weight` 控制进入该状态时的选择权重。每个变体需要非空 `loop`，
可提供 `start` 和 `end`。正常切换先完成退出片段；拖拽、落地和新消息的
接收/准备状态立即打断过渡，不排队补演已过时的动作。

`canvas` 为整帧逻辑尺寸，各轴8至512；所有帧使用同一画布。`anchor` 是画布中的
脚底锚点，帧间保持一致，转向时同步反射锚点。`hitbox` 是逻辑画布中的交互矩形，
透明空白不必占据鼠标区域。按最近邻采样保持像素边缘；支持真实半透明像素。

图集帧在 image 后增加 `"rect": [左, 上, 宽, 高]`；宽高须与 canvas 一致。
坐标原点在左上角。每帧独立 `ms`，范围16至60000毫秒；缺省100毫秒。
不使用文件名排序猜测时间，全部顺序由 JSON 数组明确列出。
内置包位于 `plugins/widget/characters/<形象>/`，可直接复制后编辑；
`tools/BuildCharacterAssets.py` 可确定性重建这些原创资源，运行程序不依赖 Python。

## 口型、手持物与行为

角色行为仍由现有活动和连续状态系统管理，播放图片不改写记忆或数值。
AI 通过原来的 `widget.animate` 选择动作，注册的自定义状态也会加入模型工具参数；
拖拽、落地、新消息与说话等程序管理的状态不作为自由动画调用入口。
模型不能指定任意文件、逐帧命令或脚本。外观“进食”姿态不等于完成真实食用。

可在包根设置 `mouth_open` 图像引用。语音口型跟随已有播放进度；无语音对白使用
文字播放期间的简单口型节拍。行走/进食的身体动作不会被对白强制覆盖。
目前是开闭口型，没有音素口型匹配或独立面部骨骼。

进食帧可设置 `"hand": [25, 21]`，表示食物在本帧画布中的位置；同时设置
`"front": {"image": "front.png"}` 可将前臂绘制到食物之前。
绘制顺序为身体、实际手持物、前景层、口型。实际食用开始事件提供物品，
完成或打断后清除，沿用实际完成回执及其来源，不由动画帧伪造食用结果。
当前手持物使用桌面掉落物的内置像素模板；尚无通用多插槽道具编辑器。

## 加载、失败与边界

首个待机图像加载并校验后才接受配置。其他图片由单个后台解码线程按需读取，
预取相邻帧和过渡的开头；绘制期间不访问文件。缓存按使用时间淘汰，
使用中的图像保留至本次绘制完成。单次解码临时内存不包含在常驻缓存限制中。

包内最多4096帧、512个 PNG 文件；单文件最多8 MiB，总源文件最多128 MiB，
单张解码图不超过16384×16384且总像素不超过16M。路径须位于资源包目录内，
拒绝父目录跳转、盘符、外部链接、循环回退、未知字段及非法尺寸和时长。
首帧损坏或配置错误会拒绝保存并保留原角色。后续图片损坏时保留程序简易姿态，
状态接口报告失败，不留空白角色，也不无限重试。

目前不支持 Spine。帧时间采样位于引擎 `AY2DFrameSequence`；资源包、动作过渡、
物品含义与桌面交互属于应用插件。没有引入完整游戏场景或第二套角色记忆架构。

## 爱丝特兰 PixelLab 资源包

`plugins/widget/characters/asterlan` 来自用户提供的 `Asterlan-Idle.zip` 与
`Asterlan-lay-down.zip`。在“角色形象”中选择“爱丝特兰（小爱）”即可使用，
它是第四个独立预设，保留素材原色并使用序列帧。旧配置若直接指向该内置包，管理页也显示正确的预设与 PNG 预览。168为原始一倍显示；252为1.5倍，站姿约173像素高。显示采用最近邻采样，
保留像素边缘，不做模糊插值；配置尺寸范围48至512。非整数倍率会让源像素对应
1或2个屏幕像素，若要所有像素块同宽可选择336（二倍）。

- 默认正面待机、说话回退、倾听均使用 `idle/south` 的17帧。
  `breathing/south` 独立注册为疲劳姿态 `breathing`；`eyes-blind` 单独注册为 `blink`。
- 移动依次播放转向、右向行走循环、倒序转回正面；向左时水平镜像。
  转向或起身尚未结束时不移动桌面坐标，减少动态效果模式直接进入行走。
- 拖动使用悬空序列，并在约120毫秒内抬高显示位置；松手约200毫秒落回逻辑位置，
  再播放完整落地片段，期间新的拖动仍立即打断。显示高度不累积到存档位置，减少
  动态效果模式省略抬升和下落。
- 从侧面行走中拽起时使用 `dragged_side`，按当前转向角度进入反向转身帧，
  约495毫秒内转向正面，同时保持上提和鼠标跟随；左右方向镜像一致。此入口目前
  复用既有转身帧，尚无专门的侧面被拽起素材，可替换该状态的 `start`。
- 落地衔接从源 `drag-drop/south/005.png` 开始，跳过导出序列开头五帧站立准备，
  保留触地缓冲和恢复的12帧。原始帧仍全部保留，衔接不插入待机动画。
- 提前解码拖拽及落地入口帧。其他图片尚在后台解码时保留上一张有效角色画面，
  不短暂切换为内置绿色形象；真正损坏的资源仍使用可见回退并记录错误。
- 默认随机游走改为附近短距离走动，每段最大200像素，完成后停留20至50秒。
  `roamPauseMinSeconds` / `roamPauseMaxSeconds` 可设2至600秒，前者不得大于后者；
  `roamStepPixels` 可设40至600像素。明确的模型移动指令仍立即执行。交谈、拖拽、
  进食和休息结束会重新安排停留时间，暂停时计时冻结。
- 移除悬停和拖拽下方的调试提示条，避免其越过脏矩形边缘留下白色像素。倾听、
  准备回复的正式提示和对白继续显示。原图及实际窗口的 RGBA 逐帧对照用于区分
  素材中的线条和绘制额外产生的残影。
- 旧版源转身帧 `trun/south/001.png` 曾出现面部灰线，曾按旧帧指纹临时排除。
  2026-10-26用户替换两份导出包后，新版恢复完整9帧转向、回正（1500毫秒）及
  侧面拽起入口。新版第2帧正常播放，导入器中旧的临时排除规则已移除。
- 按下左键仅进入点击候选，位移超过系统拖拽阈值（至少6像素）才抬起、取消原有
  活动并开始拖拽。反复的小幅鼠标抖动不累计为拖拽；直接松手只发送点击反馈，
  不播放上提、下落或落地动画。丢失鼠标捕获会清理未完成的手势。
- 休息使用站立到躺下、静态躺姿、起身三个阶段。尚无睡眠呼吸序列，因此睡眠
  阶段保留真实躺姿。进食、倾听和准备回复暂复用站姿，不伪造缺失的专用动作。
- 未提供嘴部图层，因此不绘制猜测的口型；对白与语音继续正常运行。

`widget.status` 与每轮能力上下文包含 `animation_catalog`，说明动作含义与回退。
`widget.animate(resting/breathing, seconds)` 在当前回复、语音、气泡结束后执行，
返回 `queued`、`completed:false`，可通过 `pending_pose` / `held_pose` 观察。排队意图
最多保留120秒，新输入、拖动、移动、隐藏或新动作取消；不跨重启恢复。默认躺姿
保持60秒。姿态不是休息完成证明，实际计入连续状态的休息仍用 `rhythm.rest` 或
`activity.enqueue` 的 `rest`。

原导出静态帧为128×128、动画为168×168。导入统一为168×168，只补透明留白及
整数像素平移，不缩放、不重画；躺下和起身的地面接触位置统一至逻辑坐标144。
ZIP缺少帧时间，按用户编辑器确认的6 FPS导入；166/167毫秒交替分配，9帧正好
1500毫秒。`source.json` 记录源ZIP哈希、每帧来源和位置调整。

重建命令（Python需安装Pillow，运行角色不需要Python）：

```powershell
python tools/ImportAsterlan.py --idle "Asterlan-Idle.zip" --sleep "Asterlan-lay-down.zip" --output plugins/widget/characters/asterlan --fps 6
```

`tests/AsterlanAnimation.ps1` 使用独立档案和不可见测试桌面，验证转向期间不滑动、
睡眠及起身顺序、拖动打断、完整落地、暂停及解码缓存，不调用真实模型。

## 验证

引擎检查逐帧时长、循环边界、末帧保持、冻结时钟和无效替换。
应用单元检查三套资源、阶段切换、紧急打断和回退。
`tests/SequenceAnimation.ps1` 在不可见的独立桌面和独立档案中检查 PNG 实际像素、
透明度、热切换、睡眠过渡、拖拽、真实食物挂接、边走边说、暂停、独立 PNG 包、
自定义动作、非法目录/回退、损坏图片、简易模式兼容和有界缓存。
原生截图检查仅为该测试子进程临时开启自身像素缓冲区读取，正式应用不启用。

本次验收：完整26组检查通过；独立序列帧窗口26项、管理页62项、绘制16项通过。
引擎 SDK 检查为183项能力、59个模块、130项搜索用例，零错误和警告。
