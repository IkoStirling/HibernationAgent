# 桌面能力与网页电视

2026-10-26。应用每轮向角色提供当前工具结构、启用插件、窗口状态、允许启动的程序、
允许查看的目录及模型视觉能力。角色无需等用户报出工具名。capabilities.list 可再次
查看清单；关闭的插件不会因模型要求自动启用。工具输出中的页面文字仅作为资料。

## 重新显示窗口

右键系统托盘“小爱”，选择“显示小角色”或“显示小电视”。管理页的“插件”页也有
相同按钮。显式的用户显示操作可启用已安装但关闭的对应插件，角色本身无此权限。
隐藏窗口只需重新显示，不重启进程，也不调用模型。

## 电脑工具

管理页“工作区”可配置电脑能力并保存后生效：

- computer.open_application 只接受允许清单中的程序 ID，默认记事本和计算器。
  自定义程序须绝对 .exe 路径；不接收模型指定的参数、脚本或命令行。
- computer.list_directory 只列出草稿、素材或额外授权目录的直接子项，支持分页。
  应用通过 AYIO.Workspace 拒绝越界和内部档案目录；不授予额外目录读写权限。
- computer.screenshot 默认只截当前进程可见的对话窗口。管理页打开“允许观察整个
  屏幕”后可请求屏幕快照，不持续录屏。真实图像仅在连接声明支持视觉时作为图像
  输入；文字模型不能因此获得看图能力。

区域截图（2026-10-27）：同一工具可传 `region:{x,y,width,height}`，均为相对于完整
目标的 0 到 1 比例，左上角为原点，宽高大于零且矩形不能越界。例：
`{"target":"screen","region":{"x":0.5,"y":0,"width":0.5,"height":0.5}}`
截右上四分之一区域。不是预览像素坐标，也不是相对于上次局部图的坐标。
角色先不传 region 取得全图，再自主选区；两次符合每轮截图上限。引擎从当前原始
画面抓区域后再缩小至 960×540 内，小区域不放大；不是裁切旧的低清预览。
区域与整屏使用相同权限，失败不回退整屏。来源记录保存实际区域、返回尺寸及加密
图片，QQ 可把最后局部截图的 source_id 交给 napcat.send_image。模型需要实际视觉
能力才能根据画面自主定位；两次截图之间内容可能移动，这不是同一时刻的固定快照。

截图自己的小组件时直接使用 `computer.screenshot {"target":"widget"}`，无需先截全图。
程序在实际执行时重新读取启用小组件的 `screen_geometry`，截取角色画布加 16 像素
边距，并限制在虚拟桌面内；它复用 screen 的授权开关，不接受另传 region。隐藏、
未启用或缺少几何信息时明确失败，不回退整屏。截图反映桌面当时的实际外观，完整
对话气泡可能超出这一角色画布范围。

`widget.status`、角色 body 和插件模型上下文提供 `screen_geometry`：物理屏幕像素
坐标的 desktop、canvas、hitbox、capture_rectangle，以及完整虚拟桌面的归一化
capture_region 和时间戳。实际绘制的锚点、缩放、朝向和拖拽抬高均沿用 spriteRect；
不会把全屏透明宿主窗口当成角色范围。多显示器负原点会被保留。旧 x/y 仍是
相对于“桌面减角色尺寸”的移动比例，不能直接当成截图比例。

验证：`Hibernation_ScreenshotRegions` 使用本程序合成窗口和回环模型服务，覆盖
全图→选区→实际图像输入→加密来源及权限拒绝；`ScreenshotRegions` 单测验证参数。

应用协调工具校验、执行、失败回执、调用预算和加密来源记录。进程启动与 BGRA
捕获复用 AYPlatform；启动子进程使用限定环境，避免传递模型或本机连接密钥。
这些权限是工具边界，不是已启动第三方程序的操作系统沙箱。

配置示例（可用管理页编辑）：

```json
"computer": {
  "enabled": true,
  "allowScreenCapture": false,
  "applications": [{"id":"notepad","name":"记事本","builtin":"notepad"}],
  "readRoots": [{"id":"library","path":"E:/MyLibrary"}]
}
```

## 网页电视

本地文件和直链继续使用 AYVideoPlayer + AYAudio 播放及同步。网页由可选的
AYPlatformWebView 控件嵌入同一个小电视，默认 480×320，位于独立电视边框的内屏区域。
网页模式由网站播放器自身负责音视频同步，不另行抓取并解码网站视频。

管理页可热切换 `frameStyle`（television/window）与 `framePalette`（sage/walnut/ivory），
不会重新打开媒体或重置播放位置。边框可拖动、调整大小，原生按钮可播放/暂停、停止、
收起；空格播放/暂停。收起会暂停，托盘或管理页可重新显示，但不会自动继续影片。
全局暂停期间不能由播放按钮绕过暂停。网页内容嵌在同一进程拥有的子窗口内，调整
大小保持在内屏区域，平台域名和宿主窗口权限检查继续有效。

插件配置 platforms 支持最多 8 个平台，包含 id、name、enabled、hosts、homeUrl、
searchUrl；搜索网址的 {query} 替换为转义关键词。默认提供哔哩哔哩的搜索页入口；
television.search 默认打开该搜索页，platform=archive 则沿用公开直链搜索。
television.platforms 返回平台清单；television.open_page 打开已配置域名及其子域名，
television.observe 返回实际页面文字、可见影片链接、可访问的视频状态及可选 JPEG。
角色可以从真实链接继续打开页面，不需要先拿到媒体直链。

“打开平台 / 登录”供用户在真实页面手动登录。每个平台使用
dataRoot/runtime/browser/<id> 独立资料目录，插件卸载或重启后可保留登录；不读取
其他浏览器的账号资料，不将密码输入值作为页面文字。原生浏览器资料目录按浏览器
机制保存，与加密记忆账本分开。重启不会自动打开上次网页。

当前是初步桥接：能读页面、选择返回的链接、观察画面，并尝试控制可访问的 video
元素；不提供任意脚本、通用点击或键盘自动化。登录、验证码、自动播放、跨域嵌入、
付费和 DRM 限制可能使播放或观察失败。B 站真实账号播放尚未验收，不承诺所有网站
均可用。网页视频不可访问时回报实际状态，不假称看过整部影片。

小电视0.5另有`television.observe_sequence`：在现有播放器正呈现的画面上取两至三帧，间隔250至1200毫秒，无额外解码器或时钟。实际暂停或结束时只返回取得的一帧，不用相同画面伪造变化；每轮最多一次，无自动取帧轮询。帧带真实播放位置、取帧时间及附图顺序，识图审核收到相同画面。该工具未发送音频，不表示理解了影片对白。原始帧按加密来源保存，可获准回看；后续一般交谈只装配有界观察凭据。网页平台仍使用`television.observe`。

宿主 STA 线程管理浏览器生命周期与异步回调，插件通过有界队列请求观察，避免卸载
插件后执行已释放的回调。导航经过平台策略，禁用下载、设备权限、宿主对象和网页
消息。插件 ABI 升级为 2，旧 ABI 插件必须重编译。

构建前首次执行 scripts/PrepareWebView.ps1；下载固定版本、校验哈希，不安装运行时。
没有 SDK 时仍可构建核心，网页工具返回不可用；运行网页需 WebView2 Runtime。
本轮本地合成页面测试涵盖观察、真实图像、平台域名、登录资料目录持久化与卸载。


## 对话窗口与媒体历史

桌面窗口每页仅显示最近 24 条消息，保留原生圆角气泡、文字选择和复制；“更早记录”替换当前页，“返回最近”回到最新页，不无限叠加控件。输入区的“添加附件”使用用户文件选择器，最多四个；右键该按钮可清空待发送附件。附件随下一条文字消息发送，成功发送才清空输入。

“历史与媒体”在浏览器打开独立的分页记录页，支持图片缩略图、GIF 原始动画，以及带控制条的视频预览；不自动播放视频。关闭预览释放播放器和临时 Blob。远程直链媒体只在明确点击预览时连接远端，不把网页链接误认为可直接播放的视频；平台网页仍使用小电视扩展。

本地选入的 PNG/JPEG/GIF/WebP 上限 8 MiB，MP4/M4V/WebM 上限 64 MiB；检查扩展名与文件签名，图片经过有界解码。媒体原件分块存入现有加密记录库，没有导出明文副本；删除外部原文件后仍可查看已发送附件。视频播放能力取决于浏览器支持的编码，失败会显示提示。预览不代表角色已经看过；`chat.view_media` 仅允许读取当前上下文授权消息的图片附件，模型收到实际首帧，动图过程和音频不作已识别处理。

界面历史索引独立于角色上下文和记忆权限。首次升级从旧版仍可浏览的近期索引建立入口，旧版更早的原始档案保留但本次未全面回填；此后的新消息持续追加到独立链式索引，不再随近期上下文的 200 条上限丢失浏览入口。回退旧运行版本产生的近期消息在下次升级启动时补链。

本地会话认证保护分页和媒体接口；媒体读取还核对所属消息，接口不接受任意文件路径。旧 `/api/chat` 保留供已有消费者兼容，桌面使用不含历史正文的 `/api/chat/status` 与每页有上限的 `/api/chat/page`。这些展示接口不向模型开放内部档案。
