# 桌面能力与网页电视

2026-10-26。应用每轮向角色提供当前工具结构、启用插件、窗口状态、允许启动的程序、
允许查看的目录及模型视觉能力。角色无需等用户报出工具名。capabilities.list 可再次
查看清单；关闭的插件不会因模型要求自动启用。工具输出中的页面文字仅作为资料。

## 重新显示窗口

右键系统托盘“小爱”，选择“显示小角色”或“显示小电视”。管理页的“插件”页也有
相同按钮。显式的用户显示操作可启用已安装但关闭的对应插件，角色本身无此权限。
隐藏窗口只需重新显示，不重启进程，也不调用模型。

## 电脑工具

管理页“工作区”可配置电脑能力并保存后生效：

- computer.open_application 只接受允许清单中的程序 ID，默认记事本和计算器。
  自定义程序须绝对 .exe 路径；不接收模型指定的参数、脚本或命令行。
- computer.list_directory 只列出草稿、素材或额外授权目录的直接子项，支持分页。
  应用通过 AYIO.Workspace 拒绝越界和内部档案目录；不授予额外目录读写权限。
- computer.screenshot 默认只截当前进程可见的对话窗口。管理页打开“允许观察整个
  屏幕”后可请求屏幕快照，不持续录屏。真实图像仅在连接声明支持视觉时作为图像
  输入；文字模型不能因此获得看图能力。

应用协调工具校验、执行、失败回执、调用预算和加密来源记录。进程启动与 BGRA
捕获复用 AYPlatform；启动子进程使用限定环境，避免传递模型或本机连接密钥。
这些权限是工具边界，不是已启动第三方程序的操作系统沙箱。

配置示例（可用管理页编辑）：

```json
"computer": {
  "enabled": true,
  "allowScreenCapture": false,
  "applications": [{"id":"notepad","name":"记事本","builtin":"notepad"}],
  "readRoots": [{"id":"library","path":"E:/MyLibrary"}]
}
```

## 网页电视

本地文件和直链继续使用 AYVideoPlayer + AYAudio 播放及同步。网页由可选的
AYPlatformWebView 控件嵌入同一个小电视，默认 480×320，保留后续换电视边框的空间。
网页模式由网站播放器自身负责音视频同步，不另行抓取并解码网站视频。

插件配置 platforms 支持最多 8 个平台，包含 id、name、enabled、hosts、homeUrl、
searchUrl；搜索网址的 {query} 替换为转义关键词。默认提供哔哩哔哩的搜索页入口；
television.search 默认打开该搜索页，platform=archive 则沿用公开直链搜索。
television.platforms 返回平台清单；television.open_page 打开已配置域名及其子域名，
television.observe 返回实际页面文字、可见影片链接、可访问的视频状态及可选 JPEG。
角色可以从真实链接继续打开页面，不需要先拿到媒体直链。

“打开平台 / 登录”供用户在真实页面手动登录。每个平台使用
dataRoot/runtime/browser/<id> 独立资料目录，插件卸载或重启后可保留登录；不读取
其他浏览器的账号资料，不将密码输入值作为页面文字。原生浏览器资料目录按浏览器
机制保存，与加密记忆账本分开。重启不会自动打开上次网页。

当前是初步桥接：能读页面、选择返回的链接、观察画面，并尝试控制可访问的 video
元素；不提供任意脚本、通用点击或键盘自动化。登录、验证码、自动播放、跨域嵌入、
付费和 DRM 限制可能使播放或观察失败。B 站真实账号播放尚未验收，不承诺所有网站
均可用。网页视频不可访问时回报实际状态，不假称看过整部影片。

宿主 STA 线程管理浏览器生命周期与异步回调，插件通过有界队列请求观察，避免卸载
插件后执行已释放的回调。导航经过平台策略，禁用下载、设备权限、宿主对象和网页
消息。插件 ABI 升级为 2，旧 ABI 插件必须重编译。

构建前首次执行 scripts/PrepareWebView.ps1；下载固定版本、校验哈希，不安装运行时。
没有 SDK 时仍可构建核心，网页工具返回不可用；运行网页需 WebView2 Runtime。
本轮本地合成页面测试涵盖观察、真实图像、平台域名、登录资料目录持久化与卸载。
