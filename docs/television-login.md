# 小电视网页登录

小电视边框不再显示登录按钮。打开哔哩哔哩后，后台只检查网站提供的登录布尔状态：确认未登录时自动打开独立大窗口，由用户手动登录；确认成功后自动关闭大窗口，把同一个 WebView 移回电视。窗口仍可调整大小。普通视频播放继续使用电视内的视频表现。

网页默认逐控件直连，不继承系统代理；已有 `plugins.television.browserUseSystemProxy=true` 配置可显式跟随系统代理，切换后重启应用生效（浏览器进程可能共用同一资料目录的环境）。不会改动全局环境、系统代理或其他应用。

登录态未知（网络失败、接口不可用、尚未适配的网站）不会被当成未登录。未知网站可在平台配置的 `loginDetection` 中设置 `signed_in_selector`、`signed_out_selector`，仅检测可见元素，两者同时出现或都未出现则仍为未知。B站使用固定官方 nav 接口，只保留 isLogin 布尔值；不导出账号资料、Cookie、表单或令牌。检测有请求间隔和超时，不消耗模型调用。

用户手动关闭未完成的登录窗口后，本次页面访问不会反复弹出。重新打开平台页面可再次触发检测；右键电视边框“在独立窗口登录…”和 `television.login` 保留为手动补救。对于无法识别的网站，手动窗口仍需手动关闭。dashboard 的“打开平台”采用同一自动检测流程。

移动的是同一个引擎 WebView 控制器，共用原本的平台档案。浏览器资料在 `dataRoot/runtime/browser/<platform>`，更新和重启不清理；网站可能使登录过期，程序不会承诺永久有效。这是浏览器账户资料，不是角色的加密记忆，不应公开分享。

登录期间暂停视频，拒绝角色的网页观察、控制与换片；隐藏电视不隐藏登录窗口。完成后恢复页面观察，视频保持暂停，可继续播放。关闭窗口本身不算成功证明。

验证采用独立本机合成网页，覆盖未知态手动补救、自动弹出、成功收起、过期重新提示、手动取消不重弹、已登录不提示、同页与档案保留。另有 JS 测试覆盖B站布尔适配器的缓存、失败和不泄露账号字段。不自动操作用户真实账号；真实网站登录成功依赖网站接口可用。
