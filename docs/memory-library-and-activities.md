# 记忆数据库、准备状态与自主活动

原始交谈、经历、记忆、状态和内部回执原本已存于加密 SQLite。本次继续使用同一数据库，
没有创建能在磁盘上直接搜索出明文的关键词库，也不授予角色任意 SQL 或数据库文件权限。
这里的“压缩”指浓缩检索与上下文，原始内容和历史版本始终保留。

## 两个连接的分工

- 角色连接：决定需要检索什么、读取哪段原文、是否提出整理请求，以及选择自己的活动。
- 管家连接：生成忠于原文的摘要、关键词和不确定性；审核角色的活动提案。
- 应用：限定可访问范围、核对来源和版本、验证结构与预算、保存派生记录并执行获准活动。

未启用管家时，整理请求使用当前角色连接，但来源、结构、访问权限等校验仍由程序执行。
离线模拟只生成明确标记的原文节选，不宣称完成语义理解。

角色可以使用 `memory.compact` 整理已经获得权限的记录。已有摘要可按关键词和正文相关性
检索；长记忆及旧对白在上下文中采用摘要或有标记的节选，需要细节时分段读原文。
摘要保留原始记录ID、版本、类别、不确定性和生成连接身份，类别固定为summary。
来源发生变化或访问被撤回时拒绝写入；重复整理同一来源版本返回原摘要，避免重复存储。
格式错误最多修复一次，失败后保留原文，不发布半成品。

已有的独处定时任务也会进行有限整理：满足空闲条件后，每次最多处理一条超过2000字节、
已离开最近四条记录且尚无摘要的旧交谈。候选取自最近200条对话索引；更早资料可通过
搜索读取后提出整理。它不另起一个无限后台压缩循环。每次模型调用遵从统一小时预算，
新输入可以取消独处任务。

`memory.search/read` 面向当前可访问记忆；`memory.archive_search/archive_read` 仅面向
原始对白与故事/外层经历，不开放模型轨迹、内部工具日志或密钥。搜索结果有长度上限；
原文读取采用UTF-8字节偏移，返回下一偏移与原文字节数。当前检索为有扫描预算的中文
词片/关键词相关性排序，没有部署向量服务或明文全文索引。撤回访问的闭包同样适用于
摘要与原文。工具结果留在内部，日常界面仍只展示对话。

## 小组件准备状态

编辑输入时可以呈现“在听”；接收一条新消息后先进入receiving状态，约0.35秒后进入
preparing，显示“想一想…”，等待实际回复/语音。此时停止自主移动和休息。
回复按原有音频时钟展示；沉默或失败结束准备状态，不留下永久等待提示。
这两个状态是界面反馈，不会写成角色经历，也不会伪造尚未生成的对白。

## 自主控制模式

Dashboard → 可选插件 → 桌面小角色 → **自主控制：由角色批量选择空闲活动**。
默认关闭，已有安装升级后保留现有设置；开启后无需重启。
进食和观察需要桌面小物插件，睡觉需要安静节律插件；缺少对应插件时不接收相关命令。

角色可通过 `activity.enqueue` 一次提出最多六项命令，也能查看或取消队列。
空闲时程序使用角色连接预先生成一批活动，启用管家时需整批审核通过才进入缓存。
生成失败或返回空批次均允许，下次考虑至少间隔两分钟，不要求持续活动或发声。
通常在交谈后空闲30秒开始考虑，管理页可改为5至600秒；启动或中断另有30秒退避。

| 命令 | 执行方式 |
| --- | --- |
| eat_nearest | 执行时按当前位置寻找最近可食小物，实际走近并吃完后才算完成 |
| look_nearest | 执行时寻找最近物件，观察完成后继续下一项 |
| rest | 休息15至600秒；确认实际休息姿态后开始计时 |
| wait | 安静等待1至120秒，无需调用模型或发声 |

队列按顺序执行，一次只运行一项；条目启动前从待执行队列消耗，不能重放。
物件消失、不饿、插件不可用等情况记录失败，不编造完成；实际进食/休息仍沿用插件
的有来源完成经历。计划本身不是事实记忆。队列有效期10分钟，新输入、开始编辑、
拖动、隐藏角色、关闭模式、修改设置或暂停会取消旧计划。重启保留完成结果，但取消
未完成和剩余计划，不补做离线活动。

自主模式开启时，原先小物插件的随机接近、节律插件的自动休息以及无目标随机游走
让位于这个统一队列。关闭模式后恢复原有插件设置。用户始终可继续交谈或暂停，
角色仍可以拒绝活动、保持沉默或选择无更新。

## 验证入口

`tests/MemoryActivities.ps1` 使用本机模拟的独立角色/管家连接、独立加密档案和不可见
桌面检查原文保留、关键词、分段、访问撤回、重启、无效摘要、准备状态、实际最近进食、
串行休息、前台打断和自动批量生成。它不读取正式记忆，不播放声音或修改用户桌面。
