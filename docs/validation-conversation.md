# 对话气泡、悬浮输入与拖动反应

2026-10-26。此次修正上一版用纯文本控件替代气泡的界面退化，并补上真正的键盘
输入验证。圆角背景、角色标签、左右布局恢复；气泡正文使用只读原生文字控件，
支持拖选、Ctrl+C、当前消息全选及右键复制全部对话。流式更新保留未变化的选区，
选择或向上阅读时不强制滚到底部。

中键/右键交谈打开420×62的无标题栏输入条，只有文字输入与 ↵，主动取得键盘焦点；
Enter 发送，Esc 或点击外部收起，进程存续期间保留草稿。发送走同一会话，处理后
回复仍由角色原有气泡与语音展示。输入法选词确认不会误发送。

## 单次消耗的拖动反应

可选 reactionCacheEnabled 在启动/空闲时批量生成最多六条40字内短反应，已配置的
审核连接先审核整批；格式错误、重复或拒绝结果不能入池。TTS 随后静默预合成 PCM，
只有语音准备好的条目才能被拖动消费。文字候选与消耗事务进入加密账本，音频仅在
内存；重启只恢复未消费条目，不自动重播。候选不提前成为角色经历。

拖动当下先采用用户允许的“缓存并消耗”降级方案，没有加入每次拖动的管家意图
网络判断或按需模型调用。本机慢审核夹具需要约400毫秒，已超过250毫秒交互目标，
还未计入生成和合成；因此审核移到准备阶段。正式交谈可继续表达复杂意图，之后
是否增加独立意图路由仍待实测。

前台交谈/输入会取消后台模型准备；共享调用预算，有限超时；暂停停止准备/朗读。
默认反应间隔8秒、概率45%，两者可在管理页调整。未命中概率不消费条目，但同样进入间隔，避免连续拖动刷概率。条目20分钟过期，模型/人格版本/声音/活动/心情区间变化时淘汰。拖动已迟到、
正在交谈/朗读、冷却中或缓存为空时直接跳过，不保存稍后才说的鼠标反应。
实际拖动和已说反应保留来源，最近30秒可供后续对话引用；不污染主聊天历史。
