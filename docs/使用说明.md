# 小爱桌面版：开始使用

双击项目里的 **Start.cmd**。日常只打开一个对话窗口；关闭它以后，程序仍在托盘
运行。托盘图标右键可以重新打开对话、打开管理页面、暂停活动或保存退出。
**Stop.cmd** 也能保存并退出。

主窗口保留圆角对话气泡，文字可以拖选，用 Ctrl+C 或右键“复制”；Ctrl+A 全选当前
消息，右键菜单也可“复制全部对话”。
小角色上按鼠标中键，或右键选择“交谈…”，会在它附近弹出无标题栏的输入条，
自动聚焦，末端 ↵ 表示回车发送。发送后输入条收起，回复仍通过小角色原有气泡和语音显示，
不会自动弹出回复窗口。要查看或复制记录，右键小角色选择“打开完整对话”。
两个输入入口共用同一段会话。Enter 发送，主窗口支持 Shift+Enter 换行；输入法选词
确认不会发送。点击其他地方或 Esc 收起输入条，后台存续期间保留未发送草稿。

当前正式档案保存在 **E:/Aliyat/Archives/HibernationAgent**，没有使用F盘。

## 当前离线演示能做什么

不设置任何密钥也能交谈、保存和恢复档案，运行一次固定规则的独处流程。
这能检查程序是否连贯地保存经历，但回复方式比较固定。

管理页面里的插件试用不依赖对话模型：可以手动打开电视、显示小恐龙、试读一句话，
或检查所填写城市的天气。网络插件仍然需要可用网络。

## 让模型决定自己的活动

从托盘打开管理页面，在“模型连接”中填写服务地址、接口协议和模型名称，使用
专门的“设置 API key”输入框保存密钥。启用并保存连接，再选择为当前模型。
本机兼容模型服务可以不用密钥。离线演示连接保留为恢复入口，不必删除。

调用失败时，对话输入框上方会显示简短原因，例如API余额不足、密钥无效、
连接失败、限流、超时或返回格式错误。提示保留到下一次调用成功；
充值或调整连接后需要重新发送，程序不会自动重发先前失败的私人交谈。
提示仅使用程序内置文字，不显示服务端原文、内部记忆或模型指令。

“原生 JSON Schema”“画面理解”按服务实际能力开启；不确定时先关闭原生Schema。
只有真实支持视觉的模型，才能分析电视提供的画面。更换连接沿用原有档案和状态，
不同模型的表达方式仍可能不同。

以后可以正常说“把这个问题留下，过十分钟再想想”或“找一段影像看一会儿”。
模型决定是否安排活动或使用插件；程序只执行通过检查的操作。它也可以拒绝或沉默。
后台和电脑需要保持运行，暂停或关机期间不会继续活动。

## 角色连接与独立审核

在“模型连接”中的“独立角色审核”选择审核使用的连接并启用。可以另建一个连接，
也可使用相同模型服务；角色与审核始终分开装配上下文，审核没有执行工具。
每批工具提案在执行前审核，随后仍受程序的路径、来源、预算和状态规则约束。
最终回复审核通过后才显示、朗读或显示在小角色对白里。审核可以要求角色重写或
重建本轮工作上下文；不会把拒绝、冷淡或沉默自动改成讨好。

审核连接不可用、返回格式错误或达到改写上限时，本轮停止并显示小提示。
已审核并成功执行的操作和记忆保留真实回执；最终回复被驳回不会撤销已发生的操作。
被驳回的草稿留在内部追溯记录，不作为正常角色回复装配；上下文重建保留经历、
记忆与连续状态，移除旧助手措辞，并带回已完成的操作回执，避免重复执行。
原始档案不会删除。此前包含“实验代称”等开发说明的旧助手回复也会从默认装配中排除。

审核会增加模型调用和等待时间，并共用调用预算；最多改写或重建次数可设为0至3。
离线演示使用固定规则，不调用远程审核连接。

Dashboard保存连接、审核和插件设置后立即生效；更换档案根目录、监听端口或核心
人设文件需要先停止并重启后台。直接编辑配置文件也需重启后台。管理网页更新后
刷新即可；原生对话窗口和托盘与后台属于同一进程，会随后台一起重建。

## 四个插件

通过审核的回复会在主对话窗口逐字显示；历史消息打开时直接显示全文。这是审核后
的渐进展示，不会把尚未审核的模型输出提前显示。
小角色气泡也逐字显示并自动分页，默认每页最多72个字符、每秒24个字符，换页前
停留1.2秒。优先在句号、问号或叹号后分页，长句再找逗号等边界，仍超长则按字符
续到下一页。原文完整保留，不插入省略号或为了分页改变朗读内容。

“角色说话时朗读”开启后，默认以用户设置为准；需要让角色控制是否朗读时，另外
开启“允许角色决定本次是否朗读”。整条通过审核的回复只提交一次语音播放，翻页
不会重启或切断语音，后续自动朗读会排队。系统语音默认最长60秒，可设置1至120秒；
这个用户时长上限、手动停止或暂停后台仍可结束朗读。声音播放失败会在对话窗口
显示提示。小角色的每页字数、速度、停留时间均可在“可选插件”中保存后生效。

| 插件 | 使用方法 |
|---|---|
| 浮动电视 | 启用后可试用本地素材文件名或HTTP(S)媒体直链。本地视频须在素材目录里；普通播放器网页通常不能直接播放。角色可搜索Internet Archive、控制播放并请求观察实际画面 |
| 桌面小角色 | 简单动画小恐龙，可点击、拖动；可关闭自由游走和对白。可开启拖动短反应缓存，后台一次准备多条，拖动时消耗一条；无缓存或忙碌时允许不回应 |
| 声音 | 先选“系统棒读”即可使用已安装的本机语音；可调语速、音量和最长时长。也支持返回WAV的兼容HTTP服务，服务密钥单独保存 |
| 所在地天气 | 自己填写城市，程序不推测位置。天气会缓慢影响角色参数，不在聊天窗口显示内部数值 |

插件可以分别关闭。全部关闭后只保留基础对话；模型没有未启用插件的工具。
电视播完是否交给角色处理、小角色互动是否交给角色处理，都可以单独设置。

## 记忆与保存

日常界面不提供记忆浏览器或内部操作记录。记忆的新增、修改、访问和来源由程序
管理；遗忘不会删除原始档案。角色状态渐变并持续保存，正常退出时也会保存。

管理页面可设置草稿和素材目录；更改目录不会自动搬运文件。程序配置、插件、核心
设定和内部档案不能用作角色工作区。内部存档根目录需要停后台后修改配置，没有
自动搬档按钮。

GitHub/WebDAV目前只保存远端地址意向，**不会同步或上传**。记忆文件已经加密；
当前密钥绑定本机Windows用户，尚未提供跨账户导出。备份、换机或重装前请先阅读
[完整保存说明](../README.md#加密存档与工作区)，不能只复制一个运行中的数据库文件。

本版没有整部影片自动逐帧理解、音轨转写或原版东方音色；声音是较快的系统棒读
或用户配置的兼容服务。角色效果还需要用所选择的真实模型继续体验和调整。
