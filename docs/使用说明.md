# 小爱桌面版：开始使用

双击项目里的 **Start.cmd**。日常只打开一个对话窗口；关闭它以后，程序仍在托盘
运行。托盘图标右键可以重新打开对话、打开管理页面、暂停活动或保存退出。
**Stop.cmd** 也能保存并退出。

当前正式档案保存在 **E:/Aliyat/Archives/HibernationAgent**，没有使用F盘。

## 当前离线演示能做什么

不设置任何密钥也能交谈、保存和恢复档案，运行一次固定规则的独处流程。
这能检查程序是否连贯地保存经历，但回复方式比较固定。

管理页面里的插件试用不依赖对话模型：可以手动打开电视、显示小恐龙、试读一句话，
或检查所填写城市的天气。网络插件仍然需要可用网络。

## 让模型决定自己的活动

从托盘打开管理页面，在“模型连接”中填写服务地址、接口协议和模型名称，使用
专门的“设置 API key”输入框保存密钥。启用并保存连接，再选择为当前模型。
本机兼容模型服务可以不用密钥。离线演示连接保留为恢复入口，不必删除。

“原生 JSON Schema”“画面理解”按服务实际能力开启；不确定时先关闭原生Schema。
只有真实支持视觉的模型，才能分析电视提供的画面。更换连接沿用原有档案和状态，
不同模型的表达方式仍可能不同。

以后可以正常说“把这个问题留下，过十分钟再想想”或“找一段影像看一会儿”。
模型决定是否安排活动或使用插件；程序只执行通过检查的操作。它也可以拒绝或沉默。
后台和电脑需要保持运行，暂停或关机期间不会继续活动。

## 四个插件

| 插件 | 使用方法 |
|---|---|
| 浮动电视 | 启用后可试用本地素材文件名或HTTP(S)媒体直链。本地视频须在素材目录里；普通播放器网页通常不能直接播放。角色可搜索Internet Archive、控制播放并请求观察实际画面 |
| 桌面小角色 | 启用后显示一只简单动画小恐龙，可点击、拖动；可关闭自由游走和对白。点击/拖动可以交给角色处理，连续互动会合并，也允许不回应 |
| 声音 | 先选“系统棒读”即可使用已安装的本机语音；可调语速、音量和最长时长。也支持返回WAV的兼容HTTP服务，服务密钥单独保存 |
| 所在地天气 | 自己填写城市，程序不推测位置。天气会缓慢影响角色参数，不在聊天窗口显示内部数值 |

插件可以分别关闭。全部关闭后只保留基础对话；模型没有未启用插件的工具。
电视播完是否交给角色处理、小角色互动是否交给角色处理，都可以单独设置。

## 记忆与保存

日常界面不提供记忆浏览器或内部操作记录。记忆的新增、修改、访问和来源由程序
管理；遗忘不会删除原始档案。角色状态渐变并持续保存，正常退出时也会保存。

管理页面可设置草稿和素材目录；更改目录不会自动搬运文件。程序配置、插件、核心
设定和内部档案不能用作角色工作区。内部存档根目录需要停后台后修改配置，没有
自动搬档按钮。

GitHub/WebDAV目前只保存远端地址意向，**不会同步或上传**。记忆文件已经加密；
当前密钥绑定本机Windows用户，尚未提供跨账户导出。备份、换机或重装前请先阅读
[完整保存说明](../README.md#加密存档与工作区)，不能只复制一个运行中的数据库文件。

本版没有整部影片自动逐帧理解、音轨转写或原版东方音色；声音是较快的系统棒读
或用户配置的兼容服务。角色效果还需要用所选择的真实模型继续体验和调整。
