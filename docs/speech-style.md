# 语癖与表达预设

在管理页的「可选插件」中启用「语癖切换」，选择当前预设，点击「保存插件设置」。保存后对下一次模型回复生效，通常不需要重启；安装新插件或升级后台本身后仍须重启后台加载新代码。

本次验证后的后台位于 `out/daily-runtime-20261028`，主构建目录尚未替换。先退出已有后台，可使用原来的配置启动这个独立构建：

```powershell
pwsh -NoProfile -File D:/Aliyat/HibernationAgent/scripts/Start.ps1 -BuildRoot D:/Aliyat/HibernationAgent/out/daily-runtime-20261028 -ConfigPath D:/Aliyat/HibernationAgent/config/local.json
```

这样保留已有配置、密钥位置与档案目录。独立验证包则默认 Mock 与新档案，需自行配置真实模型才能体验生成语气的变化。

内置自然、简洁、轻微迟疑、轻文学四种起点。可以新增、复制、重命名和删除未使用的预设；编辑区与「当前使用」分别选择，编辑另一个预设不会自动切换当前风格。「自然」保持空规则，若想修改它，先复制一份。页面规则预览只显示本地文字，不调用模型。

例如自建「偶尔用唔」：

```text
偶尔在犹豫、重新组织措辞时使用“唔”。平常仍然清楚直接地说话，
不要每条回复都使用，也不要固定加在句首。不改变事实、拒绝或不确定程度。
```

预设只影响可见回复的措辞。角色、记忆、情绪状态与工具权限继续使用原有机制。每次仅把当前预设的名称与规则提供给角色及独立审核；其余预设规则、编辑配置与恢复签名不加入对话上下文。桌面和 QQ 接收同一个有效选择，即使 QQ 没有电脑操作权限也能沿用表达偏好。与可选 LoRA 编辑器同时启用时，当前偏好也随已验证事实交给编辑器，结果仍经原有审核。

模型依据规则生成措辞；具体表现取决于所选模型，Mock 连接仍用于流程验证。配置切换本身不调用模型，也不额外增加一次审核。固定系统说明保持稳定，当前选择进入动态上下文，方便继续复用供应商缓存。

拖拽短反应缓存的签名包含当前预设。切换后，旧风格的未使用反应不会继续播放，新反应在已有后台预算和空闲机制下准备。已经开始的朗读不会被配置切换强行打断。

「允许角色切换已有预设」默认关闭。打开后提供 `speech_style.select`，它只能选已有 ID，不能创建预设、改写规则或扩大权限。`speech_style.observe` 只返回当前偏好与可选名称。暂停时禁止选择操作。角色选择在加密插件状态中保存；重启时仅在配置未改变且仍允许角色切换时恢复。管理页保存配置会重新应用所选默认预设。

配置示例：

```json
"speech-style": {
  "enabled": true,
  "activePreset": "occasional-wu",
  "allowModelSwitch": false,
  "presets": [
    {"id":"natural","name":"自然","instructions":""},
    {"id":"occasional-wu","name":"偶尔用唔","instructions":"偶尔在确实犹豫时自然使用‘唔’，不固定出现，不改变事实或关系。"}
  ]
}
```

最多 16 个预设；ID 使用小写英文字母起头的 1–48 位字母、数字、下划线或连字符；名称不超过 160 UTF-8 字节，规则不超过 2048 字节，单插件配置不超过 16 KiB。应用原有的总配置限制继续生效。未知 ID、重复 ID、非法 UTF-8、超长内容和多余字段均拒绝；失败时保留先前的有效配置及插件状态。

验证入口：`tests/SpeechStyle.cpp`、`tests/SpeechStyle.ps1`、`tests/SpeechStyleForms.mjs`。使用模拟服务检查活动预设投递、未选规则隔离、QQ 原生通道、稳定系统前缀、切换费用、状态恢复、错误回滚与编辑界面，不调用真实模型或 QQ。
