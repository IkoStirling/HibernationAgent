24 次均有官方 usage。不是账户扣费差值，不含同一账号上其他程序/正式小爱的调用。
用量只进入独立实验账本，不自动回填生产模型用量面板。

不能为了通过测试强迫角色吃或睡；也因此不能宣称这一组验证了真实模型的休息和进食分支。

等待而非立即继续，最后候选回复因审核预算不足而没有发布。原始错误和不完整结果保留。

## 从实测得到的修复

1. 连接不支持 wire JSON 模式时，使用提示词协议，仍逐字验证原始 JSON 与重复键、字段、目标和版本；
   不擅自修改正式连接配置，不因为兼容性降级而跳过审核。
2. 等待不再等同于放弃：保留暂停的打算，等待中的新交谈不覆盖它；明确放弃或有效期结束才移除。
   continue 可以在目标仍有效时接续原打算，生成新操作令牌，不重放旧回执。
3. 角色请求转发前先保留一个审核调用名额，剩余一笔时不先花在角色上；格式修复也遵守同一规则。
   token 预算仍逐笔保守预留，额度不足不发布未经审核的候选。没有增加真实调用或提高预算重测。

最终的等待/名额修复经过离线和独立进程验证，尚未再次用付费连接复测。不能将前面的真实样本
视为最终构建所有分支的精确验证。正式应用接入前，应再覆盖继续/放弃、未启动与执行失败、
不同来源的连续性，以及更多自然对话；不凭两三句台词认定口吻问题已经全面解决。
