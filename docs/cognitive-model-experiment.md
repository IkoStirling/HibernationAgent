# 连续认知第二阶段：角色与审核的独立模型实验

这是阶段 1 的可选扩展，未接入正式桌面或 QQ。复用 AYInference 的 Responses/Chat Completions
适配、既有角色与审核连接、HV2/DPAPI 存储和原有实验用量账本；不读取正式对白或记忆。

## 选择和执行

手动决策模式中，程序发布一个有版本的有限现场。角色可选 eat/rest/observe/wait/continue/
abandon/reply/silence。只有当前 allowed_choices 中的目标、版本与动作可以使用；动作有时长限制。
可以观察而不吃、无安排、改变主意，不要求最大化某个数值。reply 是直接台词，其他选择不夹带对白。

角色返回先经过原始 JSON 结构（包括重复键）及当前现场校验，再由独立审核判断事实、完成声明与
角色边界。审核不规定最优动作或喜好。只有批准且再次通过程序校验才交模拟执行器。
不支持服务端 JSON 模式的连接使用提示词协议和同样严格的本地验证；不会偷偷改变原连接能力配置。

角色格式/参数不合格至多修复一次；审核拒绝不立即追加改写循环。服务故障停止实验，不回退成
伪造的 Mock 回答。模型调用在这个独立进程中串行，模拟时间只由测试输入推进；正式应用接入时
仍需使用 WorkerHost 异步处理和调用完成后的版本栅栏，不将这里的同步 CLI 移进桌面消息泵。

## 运行与预算

```powershell
# 默认仅本地 HTTP 夹具，无真实请求，不读取生产配置或凭据。
./scripts/RunCognitiveModelLab.ps1
# 显式真实实验：使用已配置的唯一角色连接和独立审核连接。
./scripts/RunCognitiveModelLab.ps1 -Live -MaxCalls 24 -MaxTokens 180000
```

需要先按 cognitive-prototype.md 构建原型目标。BuildRoot 支持 build-storage.md 的环境变量或显式参数，
OutputRoot 可独立指定，默认 E:/Aliyat/Backups/HibernationAgent/cognitive-model-experiments。
存在多个候选角色连接时用 -ActorProfileId 指明，不猜测应该使用哪个付费账号。

每次实验有全新目录及锁定账本。角色、审核和修复共享 maxCalls/maxTokens；角色转发前检查至少
还有两个调用名额，为独立审核留出一笔，格式修复也如此。token 发请求前逐笔保守预留，
错误或缺失用量不计作免费调用，供应商提供完整 usage 才结算为实际 token。达到预算/十分钟期限
不继续转发。接口重定向不跟随。默认输出每次最多 2048 token，超时 20 秒，没有无限重试。
账本是本次实验的记账上限，不是供应商账户费用封顶或账单。

密钥从已有 DPAPI 凭据或配置所指定环境变量加载到进程内存，不写到连接文件、命令行、日志、
报告或数据库。连接文件只存两个实验专用环境变量名，完成后恢复其原值。真实请求经过带随机能力地址的
本地计量中继；C++ 实验连接拒绝直接远程地址。未启用 -Live 不访问生产凭据。

## 场景与报告

baseline：自由选择后的交谈、目标消失、低精力。continuity：用标明来源的合成夹具初始化一个
正在进行的进食打算，移动后打断，询问未完成/完成状态，让模型自行选择继续或放弃。
初始化不算本轮角色自主选择。可用 -Variant continuity 单独运行，调用预算同样需显式控制。

report.html 展示候选、审核后实际事件及用量；只有 visible_reply 是批准发布的对白。
report.json 包含分场景结果、有限原生输出和用量元数据，budget.json 是耐久记账。
实际场景原始记录和状态版本仍在各自 data/archive 的加密账本中。报告明文仅为合成实验诊断，
不会出现在正式角色界面。没有保存内部思维链或供应商原始响应体。

旧视图 metrics.model_calls 为决策轮数（兼容 Mock）；真实 API 笔数必须看 budget.calls，不能用
决策轮数冒充账单调用数。供应商缓存细项由原生 audit.usage 提供，缺失保持未知。

## 推广门槛

需要检查选择与实际效果的区别、上下文版本、暂停/重启、事件去重、未知完成和审核拒绝。
固定语义检查仅覆盖结构与可核对事实，不把模型选择休息/吃东西作为必过条件，也不给意识打分。
真实实验中的自由选择可能使某些动作分支未被触发；必须标明，再用带来源的初始化或离线夹具验证。
自然度、对长期偏好的影响和真实桌面表现仍须后续测试，不由一次合成实验推断。
