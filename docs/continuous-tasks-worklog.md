# 连续任务实现与验证记录（2026-10-28）

本轮实现用户要求的“对话时判断是单独回应还是持续做事”。通过同一角色调用选择闲聊、一步工具操作或 `task.start`，复用引擎 DurableQueue/WorkerHost、加密 RecordStore 和原有工具审核/执行回执。没有另建事件系统或调度器。

后台按有限步骤推进，保存短进度和下一步，支持等待补充、暂停、取消、改目标、失败退避和重启恢复。完成必须有实际工具证据，语义审核继续比较完成条件。已接受目标后，程序阻止当前对话继续执行该目标的操作，避免前后台重复工作。共享来源撤回、工作区变化和权限变化都会阻止旧目标继续。
