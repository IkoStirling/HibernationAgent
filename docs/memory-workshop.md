# 存档与记忆工坊

管理页 → 可选插件 → 存档与记忆工坊。此管理扩展由应用持有存档权限，角色工具不能创建备份、读取备份密钥或配置训练进程。页面只显示配置、数量和进度，不展示原文、摘要正文或中间提炼内容。

## 备份存档

先保存工坊设置，再点击“暂停并离线后备份”。后台保持暂停和离线；备份完成后可在工坊或“此刻”页恢复。

保存目录可指定绝对路径；留空时使用当前数据目录旁的同名 `-backups` 目录，因此正式档案在E盘时，默认备份也在E盘。不能位于角色草稿、素材、Skill、核心资源或已授权的电脑目录中。曾经使用的备份父目录继续受保护，改路径不会把旧备份开放给角色。

备份包含加密数据库的全部历史版本、记忆解密资料、状态、任务、草稿、素材、核心设定副本与配置。API密钥目录、活动服务锁及数据库临时文件不复制。原始正文与内部状态保持加密；用户草稿和素材保持原格式。

数据库通过引擎SQLite接口生成一致性快照，普通文件在复制前后检查，完成后再次核对文件哈希。只有验证完成才写入 `manifest.json` 的完整标记。此版本保证逐数据库快照和逐文件校验，不宣称多个数据库在完全同一瞬间形成全局快照。处理中发生源文件变化会停止，不覆盖旧备份。

暂停在当前文件或校验步骤结束后生效。相同后台进程内可继续；后台重启后，未完成备份需要新建，原有部分文件保留且不冒充完整备份。已完成的备份可独立恢复，不依赖工坊队列仍存在。

**当前解密资料依赖当前电脑的Windows用户密钥。** 已验证同机同用户恢复；独立跨机解密、密码保护的便携密钥导出尚未实现。恢复时将完整备份复制到单独的数据目录，保留 `runtime/memory-key.dpapi`，停止原后台后再调整配置；不要直接运行或改写唯一一份备份。

## 提炼记忆

使用审核连接生成摘要；未启用审核时使用当前连接。角色本身不参与这次管理交谈。程序验证返回结构、来源、版本和当前权限，控制调用额度、超时和重试。

“查看可处理数量”不调用模型。选择处理数量和最短长度后可加入队列；实际提炼会产生所选服务的费用。最近四条正常交谈、已经存在有效摘要或不允许访问的记录跳过。一次最多选择128条，单条最多256 KiB，扫描最多65536条/64 MiB；超过扫描预算会明确失败，不悄悄把部分扫描当完整结果。

长原文按不拆开UTF-8字符的片段逐步处理。每次把上一阶段派生摘要与下一段原文继续浓缩，每个成功片段保存加密恢复点。暂停、取消或失败不发布未覆盖完整原文的半成品。暂停/故障后可从已有位置继续；更换提炼连接或模型则使用对应的新恢复序列。

最终摘要包含原始来源ID、版本、类别、关键词、不确定性及生成连接身份，原始正文和全部旧版本保留。后续上下文仅在摘要确实比正文短且来源仍可访问时采用它，仍能按需检索原文。它是有损提炼，不保证保留所有细节，也不自动改变固定人设、发展阶段、长期偏好或即时数值。

离线Mock只生成明确标记的节选，可以验证流程，不能当作真实语义提炼效果。

## LoRA 计划

可以填写基座模型及版本、已有LoRA目录、继续训练的检查点目录、计划步数及分步保存间隔。方案进入持久队列，可暂停、取消或重新载入修改；文件路径此时只保存为配置，不读取或写入权重。

真实训练后端延后接入。页面与接口明确报告 `training_available=false`、`awaiting_backend`，没有模拟的训练进度或检查点。实际权重训练、从权重检查点恢复和中断训练必须等后端提供真实回执后才能使用。

## 顺序与恢复

- 每个设置板块、连接、插件与工坊任务都有可折叠标题。各页顶部提供名称列表和搜索，点击名称会展开对应详情；支持全部折叠或展开。
- 搜索只匹配名称、类型和标识，不检索私密记忆正文。切换搜索或折叠不会丢掉尚未保存的输入；展开状态随页面布局保存，也在当前浏览器会话内保留。
- 新连接、新程序、新目录、新平台及新工坊任务插在对应列表最前。
- 连接、插件、页面板块和工坊队列都有前移/后移按钮。连接与页面布局保存设置后持久化；工坊队列调整立即保存。
- 已保存顺序之外新出现的插件和板块先显示；排序只改变界面或待执行顺序，不改插件依赖和权限，不硬中断当前步骤。
- 提炼保存每个片段及每条记录的进度。重启后等待手动继续，不自行恢复付费调用。
- 收起已完成或已取消任务只从当前队列移除，数据库中的历史记录和已完成结果保留。

配置项为 `memoryWorkshop` 和 `dashboard`，示例见 `config/example.json`。接口统一位于受本机会话认证保护的 `/api/memory-workshop` 下，不对角色工具暴露这些管理操作。
