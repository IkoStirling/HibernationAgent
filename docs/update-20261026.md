# 2026-10-26 更新说明

本轮代码已完成验证、更新到常用程序。后台和托盘继续运行，使用

## 新增与完善

- **拖动反馈**：默认间隔8秒、45%概率触发，可配置；使用经审核、一次性消耗的反应缓存，
  提前准备语音。已有回复播放时不插队，过期或繁忙时跳过，不在很久之后补说。
- **角色外观**：完善小恐龙步态、眨眼、呼吸、悬空、落地、进食和休息动画；
  新增月羽鸟、游光形象及三套配色，管理页可预览。增加透明启动动画和界面过渡，
  遵从减少动画设置，减少不必要的重绘。
- **对话交互**：保留气泡布局并支持选择复制；中键或菜单打开独立输入条，自动聚焦，
  支持中文输入、回车发送和点击外部收起，回复仍由角色气泡显示。
- **桌面小物插件**：可出现果实、叶子、种子、纸星；角色可接近、观察、进食和种植，
  植物逐步成长。实际完成后才记录经历，状态与记录支持故障恢复和去重。
- **安静节律插件**：角色可安静观察、休息和醒来，精力逐渐变化；输入或拖动可打断。
  不强制日记、发言或额外模型调用。两个新插件均可关闭。
- **小电视**：增加电视边框、三种配色与播放/暂停/停止/收起控制，可切换普通窗口；
  继续复用引擎解码和音视频主时钟。
- **语音和调度**：完善输出设备诊断、暂停恢复和旧任务防重播；新对话可让后台独处让位，
  网络取消可及时生效。审核与缓存生成遵从所选模型的输出预算。
- **存档和构建**：新记录采用HV2加密封装，继续读取旧HV1，原始记录不改写；
  增加只读指纹核对和运行库一致性检查，修复不同构建配置的依赖混用。

## 使用与验证

从托盘打开管理页，可切换形象、调整拖动概率/间隔，以及配置或关闭各插件。
页面内保存的大部分设置立即生效；程序更新后刷新管理页，直接修改配置文件则重启后台。
详细操作见[使用说明](使用说明.md)。
