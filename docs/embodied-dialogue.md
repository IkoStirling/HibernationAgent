# 身体状态、连续活动与日常表达

角色日常表达与内部协议分别组织。角色与审核都读取角色投影，审核不再读取实验说明等管理元数据。历史对话保留内容和约定；旧表达不作为口吻模板。过去的记录、原始人设文件、阶段与连续数值均保留，没有重置记忆或将角色强制改成外向性格。

每轮输入包含 `body` 与 `body_at_input`。后者在中断旧计划和切换接收状态之前采样，避免模型只能看见准备回答。投影包含实际逻辑姿态、PNG 动画解析状态与开始/循环/结束阶段、位置/目的地/方向、动画语义目录、当前及待执行队列。绘制计数、帧文件名和内部工作编号保留在管理员诊断中。工具批次回执补充最新 body；`body.observe` 可按需再次观察，并保存真实来源。

自主控制须在插件设置开启，继续尊重暂停、隐藏、鼠标交互与用户输入。队列最多六项：

| 命令 | 参数 | 完成依据 |
|---|---|---|
| move_to | seconds=0，x/y均在0至1 | 原生组件抵达目标后的令牌回执 |
| pose | state为已有动画，seconds为1至120 | 实际进入对应动画循环后计时 |
| eat_nearest / look_nearest | seconds=0 | 执行时选真实物件，等待实际完成事件 |
| rest | seconds为15至600 | 安静节律插件的真实休息结束事件 |
| wait | seconds为1至120 | 等待时长完成 |
| interact | seconds=0，object_id为实际物件，action为look/eat/plant | 抵达目标及真实交互完成；目标消失会失败并释放队列 |
| create_drop | seconds=0，template/name/description/tint | 实际创建回执；数值、数量与寿命仍由插件控制 |
| creative_note | seconds=0，title/content/piece_kind | 创作角真实写入，程序生成作品ID并保存来源 |

每批最多两次创造小物、一次短创作；这不扩大插件权限或绕过本轮审核。耗文件操作的本地效果通过一个独立工作线程执行，桌面消息泵不等待磁盘。取消停止未发生的动作，已经提交的结果仍保存来源；关闭宿主先等待该工作结束并记录结果，再卸载插件。创作和角色创造的小物进入实际经历，后续对话可以知道自己曾做过什么。

移动采用桌面相对坐标，不受随机游走的200像素上限约束；开始/结束的转身仍由组件动画系统处理。普通模型 widget.move 请求在自主模式下也交给队列，于本轮对白结束后执行。原生移动有独立令牌，中断不视为到达；新输入、实际鼠标交互、隐藏、暂停和重启清除旧意图，不补做。缺失插件、未知姿态和不符合疲劳条件的 breathing 拒绝整批，不部分执行。

空闲规划使用同一角色连接和独立审核，一次准备多项活动；队列只剩少量时可预先补充，默认最短间隔60秒，可设30至600秒。规划读取 live body、实际物件、剩余容量和近期活动。保留无安排与等待的选择，不以持续联网实现逐帧控制。后台生成沿用本地调用额度和前台预留。关闭“自由活动”后后台不自行安排移动，用户明确安排仍通过校验。

验证：Hibernation_EmbodiedActivities 使用不可见测试桌面和模拟服务验证输入前状态、动作目录、超过200像素的移动、真实到达后串行切换、姿态、直接移动协调、中断、整批拒绝与后台批次。Unit、MemoryActivities、Continuity、AsterlanAnimation 与 CallBudget 提供相关回归检查。表达自然度另需通过实际交谈评估，结构检查不等于人格质量评分。

2026-10-27：缓存活动增加creative_continue，piece_id/expected_revision指定最近实际可见的草稿，content为最多400字新增段落，stage为draft或finished，seconds固定0。一批与creative_note合计最多一次。排队前核对作品存在与版本，执行时atelier.append再次读取文件核对；不覆盖等待期间的新修改，不重新开启finished/set_aside作品。新输入同样取消尚未发生的续写。

创作角快照提供最多两件draft的真实末尾节选（每件最多600 UTF-8字节，带版本和节选标记），让空闲规划能沿着已有作品继续。它们是工作区创作资料，不是亲历记忆或系统指令；完整内容仍用atelier.read按需读取。append保留原文与标题，组合后总长最多3000字；草稿可停笔或完成，不要求持续产出。执行成功仍生成真实续写经历。

阅读角0.2可单独开放autonomousReading，默认false，且仍需小角色自主控制开启。reference_search以query/language搜索，reference_read以同语言的实际last_search.key取摘要；二者每批合计最多一次，不在搜索尚未返回时猜下一个结果。执行在已有有界效果线程进行，新输入取消未来命令。真实阅读事件带最多600字节导言节选进入加密经历，后续规划/交谈知道看到了哪一小段；不会因此声称读完全文或生成主动发言。直接reading.search/open仍可在自主阅读关闭时按对话调用。

最新搜索结果的标题/key和一段实际阅读节选随插件状态保存，重启不产生新的阅读经历，也不重放联网。改换配置服务器后不再恢复旧服务器的现场视图；原始观察来源仍保留。资料只作为参考数据，不能提供权限。

小电视0.5新增television.observe_sequence：从现有引擎播放器正在播放的内容采样2至3帧，间隔250至1200毫秒，最多约2.4秒，不seek、不另开解码器、不改变音视频同步。暂停或结束只保留实际取得的一帧，不复制成虚假变化；来源切换或播放时间回退即结束本次观察。网页平台继续使用television.observe。每轮最多一次序列观察，无后台轮询或额外模型请求。

每帧带实际时间位置、取帧时间和附图序号；图片作为模型输入内容，角色与识图审核连接看到相同顺序的画面。原始图片保存在加密观察来源，日常回执和后续上下文只保留范围、时间与投递信息。少量帧不代表看完整段，更不代表听见声音。关闭识图时只传元数据，并明确图片没有提供；应用录音转文字仍是后续计划。

角色及自主计划的插件现场使用单独投影：保留物件属性/身份、当前动作、真实播放进度、搜索结果和已有草稿；绘制计数、缓存命中数、原生窗口矩形与同步时钟等仍在管理诊断中，不作为角色日常关注。实际工具回执及来源档案不改写，未知插件仍保留原有接口，避免隐去后续插件需要的字段。

连续活动可选带purpose（一句最多160字的活动目的），不要求输出内部思考，也不要求每一步都有理由。该打算随缓存动作、开始、完成或取消状态保留，供后续自己知道当时想做什么；它不是完成事实，也不授予权限。真实回执只证明对应动作完成，例如走到某处或写下草稿，不证明目的文字中更大的愿望已经实现。当前输入仍可取消未执行的动作，角色可以改变主意。

可选reflectOnActivities（旧配置及示例默认false）允许已有独处时段在没有未解问题时，考虑最近24小时角色真正完成的阅读摘要或创作，既包括活动队列，也包括角色直接调用工具后选择沉默的工作。一次至多三个可访问的原始来源；只走动、等待、未完成意图和管理员直接试用工具不产生此机会。先沿用空闲判断，再按至少15分钟的自动考虑间隔、背景调用预算执行；手动独处可提前考虑新内容，但仍不重复同一作品版本或同次缓存阅读。没有新内容就不调用模型。

考虑机会不强制写记忆、改兴趣、写日记或主动发言。角色仍经原有工具校验自行选择更新self或安静。成功完成（包括无更新）后，原始来源的已考虑标记与本轮结果一起加密提交，重启不重放；调用失败或前台打断不假装已考虑。作品和参考摘要保持各自性质，不提升为亲历故事。管理页提供开关，关闭不删除此前经历或关注。

缓存活动的可用种类还依据当前现场：没有进行中的棋局时不提供puzzle_press，没有搜索结果时不提供reference_read；创作区没有空位时不提供必然失败的新建活动。continuations中实际可见的旧草稿仍可缓存续写，即使它已不在最近六条作品元数据中。直接阅读、版本编辑等插件工具仍保留。

模型可以返回空活动队列。成功选择暂时无安排会延长下次后台考虑间隔，连续空计划或生成失败逐步等待，通常最多十五分钟；用户原本配置更长间隔则不缩短。实际选择、计时和计数加密保存，正常重启继续等待。新输入、鼠标互动、配置调整和真正出现的新小物可以恢复后续考虑机会，不立即额外调用模型。前台对话、已有活动执行、暂停与调用预算不受此后台退避代替。

自主规划与前台交谈都获得同一时间戳对应的可读 UTC、主机本地时间和小时。主机时区不是推测的用户所在地；不会因此伪造天气、离线活动或窗外观察。后台记忆装配使用与前台相同的当前可访问性策略。

自主活动规划与短反应准备互斥，同一主角色不同时启动这两种语言批次。手动补充缓存可以保持待处理，待正在进行的规划结束后再准备；对话输入仍优先取消后台候选。该约束不暂停视频解码、窗口动画或已就绪的朗读。
