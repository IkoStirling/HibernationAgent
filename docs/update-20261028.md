# 小爱：人格连续性与自己的生活（2026-10-28）

这一轮以同一份隔离生活档案中的接续交谈、实际创作与自主活动为主。没有读取或复制正式私人对话，也没有把实验经历写进正式角色。固定人格、阶段和已有加密档案保持原样。

## 日常相处的变化

- 普通闲聊不再每轮塞入完整棋盘、小物和草稿末句，减少背景反复牵引同一个话题。角色仍知道现场有什么，可以主动查看。
- 自己的兴趣和作品不必自动变成替用户看守或等待的任务。普通生活分享也不默认等于求助；关心、沉默、玩笑和各做各的都允许。
- 角色与审核共享表达边界、来源归属及实际行动结果。审核反馈能供下一次自主考虑参考，但不会因此立刻排队重试或强制发言。
- 对白结束时可以顺带留下少量有来源的关注和感受，不强制每轮写私记，也不另外调用模型补日记。聊天窗口仍只显示对白。

这些是给角色更多自然选择空间的规则，不能保证每次回答都合意。实验中仍出现偏抽象、解释过多、重复意象和审核改写，原记录保留。

## 兴趣、意图与当前状态

兴趣、偏好和未完打算具有来源、版本及结束缘由。同一件事反复查看不会无限强化；重新理解旧事可以留下变化，不会伪造新的经历。对方转述、自己的经历和助手旧说法分别处理。

活动队列可关联真实意图，记录实际完成、中断与未开始。动作完成不代表更大目标已经达成；角色可以继续、放下或改主意。程序限制范围、版本与数量，模型不能直接改偏好强度、关系阶段或核心人格。

感受只对有限情绪目标产生渐变影响，与精力、身体活动和时间分别管理。休息、暂停或重启不会把所有状态一起重置，也不补造离线经历。受限来源不能借关注、感受原因或历史回执重新泄露。

## 可以继续做的自己的事

- 创作后自主重读已有作品，再决定续写、改意或放着；读取有实际回执，不把计划当作已读。
- 阅读角支持导言和受限正文源文本分页，记录真正送达的范围、版本与后续位置。缓存中未送达的部分不能算读过。
- 可以回看旧的真实创作、游戏和阅读经历。早期误归类为提案的已执行游戏动作有严格只读兼容；未执行提案不可见，原档案不改写。
- 保留桌面小物、有限游戏、移动和休息等既有工具。没有物件时不虚构可互动目标，也不会把作品编号当成桌面物件编号。

具体结构及权限见[人格连续性](personality-development.md)。本轮没有扩展识图、视频压缩、远程同步或应用录音转文字。

## 验证与实际限度

共享实验账本共420次请求，记账约507万token，包含角色、审核和修复；其中6次采用保守计量。连续主档案保留59轮用户交谈，另有一次小规模空档案日常场景对照。仅少量接口探测用于确认真实可读范围，不以能力题库评价人格。

实际观察到有来源的新关注、逐渐变化的感受、主动创作及重读；这些证明相关流程跑通，不构成人格自然度评分。自主队列被接受也不等于其中每一步都已完成。

广泛回归首次50/51通过，旧协议夹具补齐新增可空字段后单项通过；后续按变更做定向验证，失败及修正过程见[开发记录](ai-logic-worklog.md)。正式更新先备份，再用独立Mock检查安装位置；不以正式角色发话作为冒烟测试。

当前运行包针对这台电脑验证。既有四个FFmpeg库仍依赖本机开发运行库，本轮没有把它包装成可跨机器分发的安装包。
