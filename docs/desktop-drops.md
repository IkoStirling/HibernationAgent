# 食物与桌面掉落物

角色可通过已注册的 `habitat.create` 创造虚拟食物或桌面小物，无需用户先介绍工具。
需要启用“桌面小物”和“桌面小角色”。`habitat.observe` 返回现存物件、创建策略和模板；
`habitat.act` 负责走近后的观察、食用、种植。旧 `habitat.place` 保留兼容。

## 属性与效果

模型可选择九种模板：浆果、叶片、种子、纸星、苹果、面包、布丁、茶、晶石。
种子种下后变成芽苗，继续沿用生长阶段。

| 字段 | 所属与含义 |
| --- | --- |
| definition.name / description | 模型命名和描述，最多40 / 240字 |
| definition.tags | 最多六个不重复的标签，各24字 |
| definition.traits | 最多六项自定义特征，值为短文本、布尔或有限数值，例如甜度、口感、是否发光 |
| definition.tint | 模型可选原色、粉、薄荷、琥珀、天蓝、紫色六种配色 |
| rules | 程序决定可食用性、饱腹效果、舒适变化、重量、品质和稀有度 |
| born / expires / id / x / y | 程序分配身份、位置与实际生命周期 |

品质为普通75%、少见20%、稀有5%，食物效果最多在模板基础上增加20%；
稀有物件有小闪光。体重单位为虚拟单位，暂用于观察信息。
饱腹目标在真实吃完后改变，当前数值仍逐渐靠近目标，避免状态跳变。

自定义特征供模型理解物品、选择行为和描述经历使用，**不会自动增加数值效果、光照、脚本或权限**。
例如“发光=true”是角色可理解的描述；当前只实现模板像素动画、配色与稀有闪光。
禁止在特征里冒充 nutrition、rarity、寿命、权限等程序字段。
超限、类型错误、未知字段、容量不足会返回失败，不会留下半创建物件。

模型调用例子：

```json
{
  "kind": "pudding",
  "definition": {
    "name": "月光布丁",
    "description": "晃起来像一小块月光。",
    "tint": "sky",
    "tags": ["柔软", "甜点"],
    "traits": [{"key": "甜度", "value": 3}]
  },
  "placement": "nearby",
  "lifetime_min_seconds": 300,
  "lifetime_max_seconds": 480
}
```

只有 kind 必填。placement 支持 nearby、left、right；位置仍由程序限制在桌面附近。
工具成功返回真实 object 与 creation_policy，失败返回错误码。
模型提出创造、走过去或吃掉都不等于动作已完成，仍以真实回执为准。
最近食物的缓存活动支持新增食物模板，不再只寻找浆果和叶片。

## 生命周期与管理设置

Dashboard → 可选插件 → 桌面小物：

- 最短与最长停留时间：默认300至600秒，允许5秒至12小时，最短不可大于最长。
- 最多同时存在：默认3，最多8；每分钟最多创建默认12，范围1至60。
- 出现间隔、自动出现、自动接近、减少动效等原有选项继续有效。

创建时可在用户设置范围内提出更小的寿命区间，程序只抽样一次并持久保存结果；
区间相等表示固定时长。旧 lifetimeSeconds 继续作为未配置新区间时的兼容上限。
寿命按程序运行时间计算：暂停时冻结，重启接续剩余时间，不补算离线时长。
隐藏小物仅隐藏画面，时间继续经过。

物件出生时平滑淡入，寿命最后一段淡出，再移出实际世界；吃完后的短暂退场动画
不参与交互，也不会重新计入食用。种子转为芽苗时交叉淡化。
使用预乘透明度的原生分层窗口；单个小物只更新附近的小块画面。
减少动效会停止摆动和闪动，保留透明度过渡。

## 保存与验证

沿用原来的加密插件存档和事件记录，未改造记忆架构。旧版小物存档自动补齐默认属性，
保留原身份、期限和位置。实际完成经历保留自定义名字、物品属性和来源；
重启不会重播未完成动作，已食用物品不会复活。

`tests/DeskDrops.ps1` 使用独立档案、不可见桌面与本机模拟模型验证创建、拒绝越权字段、
寿命区间、真实食用、缓存最近食物、原生透明度、暂停、重启与数量上限。
单元检查覆盖旧存档迁移、程序数值防伪和透明边缘。

同步修复原生对话气泡高度：直接采用正文控件报告的排版高度，避免普通文字测量与
可复制正文的换行规则不一致；首次打开也显式布置窗口。长段落、空行、中英文混排、
四种窗口宽度与选区保留由 `tests/ChatBubbleLayout.ps1` 检查，旧运行包能复现失败。

本次验证记录：桌面掉落物24项、气泡布局10项、管理页61项、绘制15项、
事件索引故障恢复15项通过。原23组回归中22组首次通过，播放器原有的异步首帧
时序检查首次未等到帧，单独重试通过；本次没有修改播放器实现。

2026-10-27：新增 habitat.arrange 与缓存队列 arrange 命令。角色先走近已有小物，再用两秒缓入缓出的位移重新摆放；只改变位置，不刷新原寿命、属性、稀有度或可食用性。最终位置有 habitat.arranged 实际回执，中途输入或拖动可中断，物件停在当时位置而不突然跳回去；该中断事实和插件状态一并持久保存。暂停冻结运动，重启不重播未完的动作。已消失、正在淡出的对象与非法坐标会被拒绝。
