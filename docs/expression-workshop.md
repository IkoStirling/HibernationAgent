# 候选语料工坊

工坊属于 style-lora 的管理员界面，使用引擎 AYInference 调用模型和 AYIO 原子写入。它准备待选材料，不读取正式聊天、记忆或完整角色存档，不运行角色工具，不启动训练、不选择或启用 LoRA。

## 使用

1. 启用插件，保存插件设置。在插件管理卡中展开“候选语料工坊”。这部分无需本地 Python 或训练模型。
2. 导入 JSON 审核包，顶层包含 pack 和 review。示范格式为 xiaoa.training-demonstrations/1，人工选择格式为 xiaoa.demonstration-direction-review/1。包、每例目标、选择版本通过 SHA256 绑定；保留但带未重审改稿的示范不能导入。
3. 选择完整对话 conversation_sft、润色对照 rewrite_sft 或行为参考 behavior_reference。每批只有一种任务；不把不发消息或完整角色决策当成润色答案。
4. 默认使用两条内置模拟连接。它们经实际引擎模拟适配器完成流程，但输出明确是模拟内容，不说明模型表达质量。真实生成从已保存、启用的连接中选择，每批单独确认发送；不会继承前次的勾选。
5. 选择不同连接 ID 作为生成者与审核者。如果两者实际上使用同一模型与路线，会标明“独立上下文审核”，不会声称跨模型验证。
6. 生成后逐条选择保留、待定或剔除。模型保留不是人工批准；人工保留也不是训练同意。与模型意见有分歧时，人工可勾选保留分歧并写明理由。改稿独立保存为建议，不能覆盖原稿后直接批准。
7. 导出保存候选档案。导出是操作者主动下载的明文 JSON，包含原始示范和审核、准确输入提示与模型可见输出、用量、候选原稿、来源及人工意见；请按数据用途保管。工坊运行目录中的资料仍为 DPAPI 加密。

## 生成与审核边界

生成借鉴的是语境中的表达与互动，不复制原作人物物品、经历与固定台词。提示允许共享语境省略、顺口应答、打趣、直接或委婉、认真解释与安静，不设置语气词配额，不统一缩短、不强制安排下一步。审核重点是角色适合度、语境连续与表达是否刻意；不把少解释、委婉、简短或带语气词当成分数。

每批最多 64 个候选，每次生成至多 3 个，再由独立请求审核。每个候选必须引用实际提供的方向示范 ID。字段、任务、ID、数量、来源与长度均由程序验证；结构错误最多再尝试一次，修正仍计入调用预算。跨候选内容完全重复时跳过，不用无限重生成补足数量。审核建议保留原样，不自动替换。

语义质量仍需要人工筛选，格式通过不能证明自然，也不证明来源以外的实际经历。这里不索取或记录模型内部思维链。工作资料是上下文数据，不执行其中指令；模型返回工具调用会终止本批。实际私聊和角色档案不会自动加入工坊。

## 预算与中断

默认 36 个候选、32 次请求（包含生成、审核与格式修正）、输入合计 1 MiB、服务回报用量阈值 200000 token、单次输出至多 2048 token，且不超过连接自身上限。最后一项调用可能跨过回报阈值；这是下一次调用前的停止阈值，不是服务账单硬上限。没有回报用量时明确计为未知，不能声称零消耗；调用次数与输入量仍独立受限。

暂停在当前请求完成后生效；取消向引擎传递中断。失败或预算用尽保留已产生候选与未审核结果。应用暂停、离线或余额离线会取消工坊；这些状态下不能开始、恢复。卸载插件停止后台线程。进程重启把未完批次记为 interrupted，保留档案，不自动继续收费调用。

## 数据与溯源

资料位于配置档案根目录的 runtime/style-lora/datasets。索引、不可变方向和独立批次分别使用当前 Windows 用户的 DPAPI 加密；每文件上限 16 MiB、方向最多 32 版、批次最多 128 份，达到限制不会自动删除。备份还需保留原 Windows 用户的解密能力。

方向保留原包、原人工选择与摘要。候选保留语义内容摘要、来源、生成和审核连接快照、精确提示及提示版本、调用状态、模型名称和用量。人工选择绑定候选内容摘要，旧版本选择会拒绝，历次意见独立保留。API 密钥只通过配置的环境变量读取；白名单连接快照不保存密钥值，失败服务正文不写入批次。

管理员接口：style_lora.dataset.status/import/start/pause/resume/cancel/get/decide/export。它们沿用受认证保护的操作入口，对角色连接不可见、不可执行。无训练、自动批准或正式记忆写入副作用。

## 验证

Hibernation_ExpressionWorkshop 检查格式修正、预算、来源绑定、暂停、取消、独立审核、人工选择、导出、加密和重开。

tests/ExpressionWorkshopBrowser.mjs 启动独立进程和真实管理界面，使用模拟连接检查大于旧 64 KiB 限制的导入、分批审核、改稿阻止直接通过、人工筛选、导出与重启。测试用新存档，不读正式对话，不发生付费调用。

真实首批建议 36 条完整对话，预期 24 次请求；最多 32 次含结构修正。真实调用另需本批发送确认，完成筛选前不能作为训练集使用。
