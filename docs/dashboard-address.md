# 固定管理页面地址（2026-11-05）

正式配置固定 port=61024，对应 http://127.0.0.1:61024/ 。只监听 IPv4 回环地址；端口被占用时启动失败，不换随机端口。隔离测试仍可显式设置 port=0 来选择空闲端口。

普通脚本启动与开机 quick-start 复用 runtime/.ipc-token.dpapi 中的本机登录凭据；凭据不写日志或明文配置。首次没有凭据，或当前 Windows 用户无法读取／内容不合法时才重新创建。原始档案与模型密钥不变。需要撤销管理登录时，应在停止后台后更换该本机凭据。

从旧随机端口迁移时需要通过托盘打开一次新地址；新的浏览器 origin 保存登录后，后续后台重启可以继续使用同一页面，不必重新从托盘打开。管理页面仍要求原有登录授权，仅固定端口不会开放匿名操作。

Windows 引擎 LocalService 使用独占绑定，避免两个实例共享同一个端口；已验证脚本重启、原生 quick-start、旧 Bearer 仍有效、端口冲突明确失败。测试采用隔离 Mock 档案，未调用付费模型。
