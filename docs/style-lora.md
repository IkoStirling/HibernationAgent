# 表达语料与可选薄 LoRA

## 此前分析的记录

“接住、接下、不敢瞎猜、不敢瞎说、才是病根、能短就短、不解释、不总结”不能仅按词禁止。当前固定源码未直接写入这些完整话术，但真实性、少解释、少汇报等要求可能被过度执行，再与模型常见措辞、旧对白及审核意见共同强化。具体来源需查看该轮角色初稿、审核指导与实际历史，不能仅由词形断定训练来源。

完整句子本身不是问题，故意留半句也不等于自然。只有负面限制容易产生另一套固定话术。优先收集带上下文的认可表达、原回复与认可修改的对照、具体不认可的原因；保留长句、拒绝、不确定和正常使用这些词的正例。人类语料也须按小爱的表达取舍，不能直接学成某一类网友。

原始经历、模型无关的事件摘要、人格发展与当前状态分别保留。LoRA只是可替换的表达衍生物，不是权威记忆，不自动改变核心人格或阶段；不能准确恢复的细节仍从原档案检索。现有机械回复不因“训练”而自动变成正面样本。

## 插件范围

`style-lora`使用独立本地小模型，以监督微调训练一个对白编辑适配器。薄是低秩参数容量，不保证只影响语气，也不保证比原稿好。主模型继续使用原连接；普通远程 API 不会加载此适配器。基座更新时，风格语料仍保留，适配器需重新匹配或训练。

安装、训练、选择版本、实际启用四步分开；训练完成绝不自动启用。插件管理页提供导入、训练、取消、状态、版本选择和预览。日常角色工具清单不提供这些管理操作，角色不能给自己导入“认可样本”、触发训练或更换版本。

第一版使用SFT：输入是上下文、事实与原稿，目标是操作者认可的修改。损失只计算认可的输出。原稿与修改也保留为未来偏好训练材料，本版没有实现或声称执行DPO。

每批从指定基座重新训练，使用当前语料库按固定随机种子打乱采样；不是在所选旧LoRA上继续修改。已有版本保持不变。步数较少时未必覆盖全部样本，版本记录区分语料总数与实际训练过的样本数，加密产物内保留实际样本ID和超参数。训练损失不表示表达质量。

## 准备环境

运行 `scripts/PrepareStyleLora.ps1` 在 `out/deps/style-lora-venv` 创建独立 Python 环境，安装CPU PyTorch及依赖。可显式使用`-TorchBuild cu128`选择官方CUDA构建；是否能用GPU以状态及实际PyTorch检测为准。不会修改系统Python或下载语言模型。

没有本地模型时，可显式加`-DownloadModel Qwen/Qwen3-0.6B -ModelDirectory D:/Aliyat/HibernationAgent/out/models/style-base`下载基座。此选项会联网占用模型磁盘空间，只取模型与分词器数据，不取远程Python代码；普通准备命令不下载模型。测试不需要它，使用本机创建的微型随机模型。安装前应核对模型与自己的设备，示例不表示已训练好小爱的风格。

插件设置填写：

- `pythonExecutable`：该环境的`Scripts/python.exe`绝对路径。
- `baseModelPath`：已经下载好的本地模型目录，含`config.json`、tokenizer和`safetensors`权重。禁止远程代码与运行时联网下载。
- `rank`、`maxSteps`、`learningRate`、`maxSequenceLength`和`trainingTimeoutSeconds`：本批训练上限。
- `device`：auto/cpu/cuda。小显存机器应从小模型、短序列和单样本批次开始；不预先保证某模型能放入显存。

导入JSONL，每行一个对象。示例是格式示意，不应把同一句话复制成整批训练：

```json
{"context":[{"role":"user","text":"这个工具能在另一个桌宠里用吗？"}],"original":"我不清楚，不敢瞎说。","preferred":"这个我不清楚。","reason":"前半句已表达未知，后半句重复表态；没有提高确定程度。","facts":"尚未核对兼容性。","source":"operator"}
```

导入时需明确勾选认可。工作进程要求`consent=true`且每条`approved=true`；重复内容去重，累计最多10000条/32MiB。训练序列过长会明确失败，不能悄悄截掉事实或答案。没有自动抓取网络语料、读取正式聊天或将所有已发布对白当作优质数据的行为。

## 启用与含义核对

训练成功后选择版本ID，再打开`applyEnabled`。`adapterScale=0`旁路，1使用正常LoRA强度；调整秩只影响下一批训练，不会改变已存版本。缺少已训练版本、依赖、匹配基座，或本地服务超时，均保留原稿并在加密trace记录原因。

桌面和QQ用户对话中，编辑最多尝试一次，发生在最终语义审核之前；原稿与候选一起送给该会话的独立审核连接，核对主体、否定、拒绝、不确定性、数量、专名和动作完成状态。没有独立审核时不会自动应用。QQ通过有效会话的原生专用转发调用同一编辑器，不因此获得训练、导入或电脑控制权限。数字/URL变化另有保守机械检查，但这不等于语义等价保证。审核故障仍遵守原有停止规则，不为了风格放行未审内容。

只编辑用户可见文字，工具、记忆、状态、阶段和操作回执不交给编辑器改写。语音与气泡使用最终获准文本。编辑失败不重做工具，也不会变成“已执行”的新经历。插件关闭后恢复原路径。

## 保存与限制

语料、适配器权重和训练清单位于档案的`runtime/style-lora`，使用当前Windows用户DPAPI加密。训练数据经本机回环、随机凭证保护的内部接口送达，不写到进程参数、日志或明文临时文件；适配器从内存解密加载。基座模型自身不是私人经历，仍使用用户指定的普通本地模型目录。备份必须包含这些加密文件及对应Windows用户的恢复能力，不能假定拷贝到另一用户即可解密。

累计最多保留16个完成版本，达到上限不会自动删除旧版本；需要先由管理员备份整理。单个加密产物最多128MiB，写入前检查磁盘余量。程序不以反复训练填满存储空间。

训练是后台任务，支持步数/时间上限、取消；暂停应用或卸载插件会停止其受控工作进程及训练，重启不恢复未完成训练。没有完成的产物不列为可用版本。默认不启用编辑，不自动训练，不收费调用主模型，不上传语料。

小型随机模型训练仅验证数据、梯度、加密保存、重载和开关流程，不证明真实语言质量。判断风格需要保留未参与训练的日常场景，并由操作者按原意和人格选择，不能以损失下降或禁词减少认定自然度已解决。

参考：[LoRA](https://huggingface.co/docs/peft/main/en/conceptual_guides/lora)、[SFT](https://huggingface.co/docs/trl/sft_trainer)、[偏好数据与DPO](https://huggingface.co/docs/trl/dpo_trainer)。

隔离源码由已提交基线与本插件改动组成，避免纳入另一个开发任务尚未完成的代码。通过完整编译、8组定向CTest（单元、原生工具、持续性、独立进程、配置、LoRA宿主、真实训练工作进程、QQ风格审核）及8项真实浏览器页面检查。另有原QQ回归通过。使用合成测试资料，无正式私人对话导入，无付费模型调用。

微型随机基座实际完成120步梯度训练，验证只训练LoRA参数、审批导入、加密保存与重载、匹配基座、取消、鉴权及零强度旁路。该结果验证训练通路，不能作为中文自然度或小爱人格质量的成果。本次未下载正式语言基座，未开启正式档案的自动编辑。
