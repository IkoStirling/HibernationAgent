# 桌面小物：可选的生活片段

管理页启用“桌面小物”时一并启用桌面小角色。默认最多三件普通物件，每两分钟
附近可能出现一件，十分钟后消失；可关闭自动出现或自主接近。角色可自行选择
看、吃或种下，不要求每件都回应。相同且未变化的物件不会不断被自主重新发现。

模型获得 habitat.observe/place/act/show 工具。act 的 accepted 仅表示接受意图，
需要角色实际走到并完成动画，才有 consumed/inspected/planted 回执。用户拖走角色、
输入、新一轮对话、物件到期、隐藏窗口或暂停都会中断或冻结动作，不在之后补做
过期意图。管理页查询不打断正常动作。隐藏后可由管理页或模型再次显示。

食欲与舒适感由程序缓慢变化，没有直接改数值的模型工具。不饿时可以拒绝食用。
种子种下后保留为芽苗，运行10、30、60分钟会进入新的生长阶段；暂停冻结，重启
保留生长进度，离线时段不补算。收起窗口时已有植物继续在后台生长，但不发起新的
接近动作；暂停后台才冻结时间。未完成动作重启后取消，不悄悄重播。

完成经历保留真实来源，最近八条可供后续交谈使用，原始档案持续保存。候选动作
不能提前成为事实记忆。正文仍在加密账本，已有事件总线的 agent.world.habitat.*
只索引类型、编号、时间和状态，支持前缀过滤，不公开记忆内容。

默认不因吃完而额外调用模型；开启“吃完或种下后允许主动交谈”才会提交可合并、
可过期的事件，仍受调用预算、空闲和暂停限制，也允许沉默。不会强制生成日记。

当前是原创像素图形和简单动作；没有现实饮食、生理或设备传感能力。测试使用
独立档案，不把合成经历写入正式角色。tests/DeskWorld.ps1 覆盖动作、来源审批、
中断、重启、依赖、事件通道和隐藏重开；tests/WorldSoak.ps1 在不可见桌面长期
验证绘制、GDI资源、移动与种植，不切换用户当前桌面。

出现、消失与实际动作完成时，物件状态和对应经历在一次账本事务中保存，避免两次
定期保存之间意外退出造成已吃食物复生。事件索引另有持久待办标志；索引暂不可用
时保留真实经历，后续重试。重复发布使用原事件身份，确认成功后再标记已索引。
`tests/WorldJournalRecovery.ps1` 的15项独立进程检查实际锁住索引库、完成食用、强制
终止本测试进程并重启，验证一次经历、无复生、补索引、正文不泄漏；另注入“索引已
存在但待办未确认”的等价状态验证幂等恢复。夹具只接受明确标记的合成档案。
