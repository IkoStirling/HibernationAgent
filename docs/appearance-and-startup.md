# 外观与启动表现

2026-10-26。管理页“插件”提供 dinosaur、moonbird、lumen 三套原创像素形象，
forest、mist、amber 三套配色。形象与人格、发展阶段分别保存；切换形象不重置记忆。
动作包括呼吸、眨眼、交替步态、转身、拖拽、落地缓冲、观察、休息、食用与朗读嘴形。
嘴形跟随实际语音字符进度，播放结束后的气泡停留阶段不会继续假装朗读。

管理页形象选择旁会显示静止、走动、休息、说话四种姿态。预览直接使用原生小角色
共享像素定义，选择配色立即更新，保存后才切换桌面外观；不会因此重建角色档案。
预览为静态图，不在后台轮询时反复播放动画或创建额外计时器。

桌面层只在实际像素姿态、位置、对白或配色变化时请求重绘，静止小物不持续刷新。
普通角色动画最多约30次每秒，拖动和对白事件即时更新。移动会清除原位置，暂停后
仍可切换静态形象和尺寸；放大时把位置留在屏幕范围内，不冻结用户的拖动操作。
`tests/RenderingEfficiency.ps1` 在不可见独立桌面检查真实重绘次数和窗口缓冲像素，
包含旧位置无残影、减少动画、暂停、边缘放大与切换形象；不以空画面算通过。

管理页“概览”的界面设置可关闭下次启动动画，或立即启用减少动态效果。系统关闭
客户端动画时同样减少动作。主窗口与输入条重新显示时短暂淡入；忙碌只在状态处
显示动态提示，不重复闪烁发送按钮。文字选择、输入法和已有草稿不因动效重建。

启动标记在当前显示器工作区中央以透明背景置顶显示；鼠标穿透，不取得键盘焦点。
后台就绪后自动淡出，异常慢启动最多显示8秒；退出回收线程与绘图资源。无插件模式
同样可用。所有原生浮层在创建之前统一使用物理屏幕坐标，避免 Windows 缩放后
颜色透明窗口的绘制位置与鼠标命中位置不一致。

`design/startup.html` 可独立预览三套配色、重播和减少动画。真实实现共享
`SplashPixels.h` 的像素生成器；AppearancePreview 的 `--splash` 导出带透明通道 PNG。
常规 PrintWindow 截图不保留这种浮层的透明通道，不用它判断实际背景是否透明。

验证：18组回归全部通过；原生对话28项、缓存20项、动画22项、桌面物件19项、
启动13项通过。浏览器45项检查包含界面设置保存与启动设计。像素检查验证透明角点、
预乘通道与完整淡出；原生检查验证置顶/穿透/无焦点/居中、后台可用和自动退出。
这不代表已经在多台不同 DPI 的真实机器上完成验收。
