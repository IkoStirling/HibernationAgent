## 目标与科学边界

借鉴循环处理、有限工作空间、内感受调节和自我模型，改善连续性、注意选择、
行动结果判断及经历形成。这是可检验的软件架构实验，不是意识实现或意识测量。
模型自述、拟人措辞、负面数值、持续运行或模块数量不能作为具有体验的证据。

参考：
- https://arxiv.org/html/2308.08708v3 （多理论候选指标，并非统一充分条件）
- https://pmc.ncbi.nlm.nih.gov/articles/PMC5062097/ （内感受理论；软件应用属于类比）

## 阶段与退出条件

|阶段|交付|进入下一阶段的条件|
|---|---|---|
|0 稳定基线|保留当前源码、分离的构建产物、版本/指纹及验证记录|可定位源码与运行文件；原有改动、配置、存档不丢失|
|1 独立闭环|模拟世界、模拟模型、连续身体状态、有限注意、打算、预期和真实模拟回执|成功/失败/中断/未知分清；可重放、暂停、重启|
|2 模型实验|把受限选择接到真实模型；保持现有角色/审核职责|少量有预算的合成场景有效；不因错误输出执行动作|
|3 应用接入|桌面、QQ、自主活动和短反应共用协调入口；可关闭回退|无冲突动作、过期补做；前台响应及时；既有功能回归通过|
|4 自我与记忆|自身事实、当前判断、打算和长期档案分别管理|来源、版本、不确定性与撤回一致；更换模型可延续|
|5 长期扩展|按需主动观察、注意监测、经验性偏好、跨会话活动|单项对照证明有益，调用/输入/延迟在预算内|

不以日期替代验收，不同时重做全部记忆或增加多套情绪系统。允许实验无收益并撤回。

## 最小原型范围

使用独立可执行程序和合成世界，不控制真实桌面、不加载生产配置、不读取生产档案，
不访问网络、不消耗 API。复用现有 RoleState、加密账本和引擎存储；不另建生产事件系统。
原型协议是实验边界，尚不是正式 turn-v1 的替代，也不宣称已接入线上小爱。

1. 身体：沿用精力连续变化；实验食欲作为本地模拟值，模型不能直接改数值。
2. 注意：一个主要焦点，候选有上限，具备驻留/切换门槛；用户消息及管理员控制另有优先级。
3. 打算：待开始、执行中、搁置、完成、失败、放弃和结果未知分别记录。
4. 预期：只含目标、成功条件及期限，不收集内部思维链。
5. 回执：accepted 不等于 completed；核对动作令牌、目标身份/版本、实际结果。
6. 记忆：只将已观察的结果写为经历，计划/预期另存；原始事件不回写。
7. 恢复：暂停冻结模拟时间；重启取消未确认执行，不补算离线活动，不重放旧动作。

闭环例子：食欲提高 → 苹果成为候选 → 选择接近 → 实际抵达 → 开始食用 → 确认完成 →
更新食欲与经历。苹果消失、拖动/消息打断、超时分别形成不同结果，不能宣称吃过。
低精力可以选择休息；不要求每次焦点变化都产生对白或调用模型。

## 模型与审核职责

程序拥有时钟、身体事实、权限、队列、动作执行和结果核对。角色连接理解处境、选择
关注并提出打算。审核检查事实/来源/操作边界，不代替角色决定喜好，不要求每个微动作
单独审核。网络失败或余额不足保持本地过程，不虚构离线经历。

真实模型阶段使用有界候选和版本栅栏，格式/越界/过期输出拒绝且有限重试。稳定规则、
工具定义在前，变化事件在后；不为缓存命中累积无用历史。运行条件（API余额、网络）
与模拟身体（精力、舒适）分别表示，不自动将技术故障解释为痛苦或被抛弃。

## 后续接口与代码归属

- 事件总线负责传递与索引；工作空间负责筛选、驻留、切换及恢复，两者不等同。
- 通用事件选择/调度/反馈追踪经验证后才考虑回收到引擎，并补模块测试、文档与 SDK。
- 小爱的需要、关注规则、身份和经历解释留在应用；插件提供观察、动作及实际结果。
- 当前工作空间、自身事实、判断、打算和原始档案分开；原型不提前锁定未来记忆数据库。
- 视觉按当前问题触发，有采样/费用预算；播放完成不等于用户听到，少量视频帧不等于看完。

## 验收与对照

固定场景覆盖：正常接近并食用、低精力休息、无事安静、重复观察、目标消失、旧版本回执、
接受但未完成、工具失败、未知结果、前台打断和恢复、暂停、重启、无效模型输出。
同一场景可在启用/关闭注意驻留时重放，对比焦点切换；关闭结果核对的对照只运行在实验里。

统计实际焦点切换、模型调用、动作开始/完成/失败/中断、过期回执拒绝和错误完成数。
后续加入延迟、输入/输出 token 与估算/实际费用的明确区分。不能用命中率或主动说话数量
单独验收，更不能将这些指标称为意识评分。

## 推进原则

每阶段使用独立数据和开关。先小范围验证，再接入正式应用。保留原始记录和明确版本；
同一操作幂等，中断不抹掉实际效果。审计只存必要结构化信息，不存密钥或内部思维链。
稳定基线、构建与原型入口见 cognitive-prototype.md 和 stable-baseline.md。
