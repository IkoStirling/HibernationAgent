# 应用默认直连（2026-11-04）

小爱模型连接和阅读、天气、语音服务、小电视直链等应用请求默认不读取系统代理；现有模型/插件的 useSystemProxy 已关闭，proxyOrigin 已清空。直连失败不会自动再试系统代理。用户明确配置专用代理或开启相应系统代理开关时，支持该配置的连接仍可使用代理。

启动时仅在小爱进程内清除 HTTP_PROXY/HTTPS_PROXY/ALL_PROXY 及小写变量，子进程默认继承直连环境；不会修改 Windows 用户或机器环境变量、系统代理、浏览器或正在运行的外部进程。导师子进程也先清除继承代理；显式配置的导师代理可覆盖。QQ 媒体抓取走直连；已独立运行的 NapCat/QQ 网络设置不由小爱修改。

小电视内嵌网页默认追加 WebView2 的 --no-proxy-server 浏览器参数（Microsoft 文档：https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/webview-features-flags）。保留其他浏览器参数和本机平台档案，不删除 Cookie/登录会话。dashboard 的“网页窗口跟随系统代理”默认关闭，修改后重启后台生效；此开关与直链/API 的代理开关分开。

这是应用层代理选择，不会绕过系统 VPN/TUN、透明网关或企业强制网络策略。需要代理才能访问的服务在直连下可能不可达；应对该连接手动配置，不自动把整个小爱切回系统代理。

验证：独立 DirectNetwork 进程检查代理环境清理、保留其他 WebView 参数、禁用代理参数和重复初始化；配置检查与播放器/登录/陪看等回归。正式激活后再核对配置及 WebView 子进程标志。测试不使用私人内容或付费模型。
