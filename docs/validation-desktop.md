逐帧理解、音轨转写、原版AquesTalk音色、远端同步、跨机器安装包、系统自启动或
多角色协作。远端仅保存配置意向，不上传。未执行完整游戏Runtime/Renderer/Editor、
Release、ASan和跨平台回归，不能由上述定向检查推导这些结果。
