# 可选原生插件

## 操作导师（mentor，默认启用）

导师是小爱可自行选择的求助工具。`mentor.ask` 询问方法，`mentor.execute` 把具体
电脑/应用操作直接交给导师执行。两者都提供目标、障碍、已尝试的方法及最多四个
候选操作工具名；宿主附上本次实际可用工具定义。执行模式还附上已授权的程序、
目录和截图能力，使导师能选择实际程序 ID，而不是猜测。

询问模式返回最多四步建议，由小爱选择采纳。执行模式由应用立即按顺序执行导师
所选步骤，不需要小爱再逐步发工具调用；每一步仍经过当前工具目录、参数与原有
工作区/电脑权限校验。导师不替换角色模型、审核连接、人设或记忆系统。直接执行
默认开启，可在 Dashboard 的“允许导师通过已授权工具直接执行”单独关闭。
本版范围是现有已授权电脑与应用工具，不新增任意终端命令或全桌面键鼠自动化。
缺少能力时应明确返回 blocked，不用其他工具绕开。

默认后端是本机 Codex 的 ChatGPT 账号登录。Dashboard 的“操作导师”中可关闭整个
插件、选择“暂不连接导师”、指定 Codex 可执行文件或导师模型；原有角色连接不改变。
程序从 PATH 寻找 `codex.exe`，也可配置绝对 EXE 路径。先在电脑上完成 `codex login`，
插件检查 `codex login status`，只使用 ChatGPT 登录；不读取、复制或展示登录凭证，
不自动改用 API Key。仅安装或开启插件、查看 `mentor.status` 都不会请求模型。
默认将当前 Windows 的静态系统代理独立传给导师子进程，也可配置专用 HTTP 代理；
不改动宿主环境。自动 PAC 脚本不在此版本解析范围，需要填入明确代理。

每次咨询/委托使用独立、临时的 `codex exec`，忽略用户配置和项目规则，关闭 shell、
子代理、应用连接和网页搜索，采用 read-only 沙箱；不恢复其他聊天。只发送这次
必要的目标/障碍/尝试和所选工具说明，不自动附上正式档案、完整交谈、人格或数值。
任务文本以进程参数传入，不生成明文任务/输出文件；运行目录只保存不含私人内容的
返回格式 schema。Codex 的账号存储与诊断行为由其自身维护，`--ephemeral` 关闭会话
rollout 文件持久化；应用不把 CLI 的原始日志或内部推理写进记录或显示给用户。

导师必须返回完整结构。程序校验格式、步数、工具是否在本次选择中和参数 schema，
拒绝未知工具、递归求助和记忆/人格修改指令。询问模式成功结果带有
`advisory_only=true`、`operations_executed=false` 和加密来源记录。执行模式只有宿主
实际执行后才产生执行回执，并分别报告尝试/成功步数、失败、取消和待完成效果；
排队意图不视为已经完成。任一步失败后停止后续步骤，部分成功仍明确返回，不用
导师总结覆盖真实结果。截图只返回真实来源与元数据，需要通过 observation.revisit
实际附图后才能声称看过内容。咨询失败只返回有限错误码，小爱仍可继续回复或行动。

委托意图及逐步结果写入加密的 ha.mentor-execution 记录。重复的同轮同参数委托
复用已保存结果；审核改写也不重新执行。中断时尚未保存结果的操作明确标为不确定，
不自动重放；不承诺外部副作用具有数据库事务或通用严格一次执行语义。

默认咨询/委托合计每小时最多 12 次、间隔至少 60 秒、每轮最多一次、35 秒模型超时，均可配置。
本地次数限制保存于加密插件快照，包含失败尝试；它是导师进程请求次数，不是官方
token/计费统计，独立于原角色/审核的应用预算。未登录、额度不足、网络/模型失败、
超时和无效建议均不会让导师接管会话。正式权限边界仍以应用的实际校验为准。

依据：[Codex 非交互调用、账号复用、临时会话与结构化输出](https://learn.chatgpt.com/docs/non-interactive-mode)，
[Codex 功能开关](https://learn.chatgpt.com/docs/config-file/config-reference)。
验证：`Hibernation_UnitTests` 中 Mentor 套件使用独立子进程覆盖超时、失败、错误建议、
取消与重启额度；`Hibernation_Mentor` 使用独立存档验证小爱求助后通过原工具继续执行，
只显示最终对白。真实账号验证需显式运行 `tests/Mentor.ps1 -Live`，不读取正式档案。

## 原生插件接口

**Date:**2026-10-26 · **API version:**2 · **Owner:**HibernationAgent

插件放在配置 pluginRoot 的独立子目录，每个目录包含 plugin.json 和匹配 DLL。
清单目录名必须等于 id，library 是同目录文件名，api_version 为2。宿主不会按模型
给出的路径加载动态库；只有管理员已安装并启用的插件进入工具目录。

```json
{
  "id":"example",
  "name":"示例",
  "description":"独立能力",
  "version":"0.3.0",
  "api_version":2,
  "library":"Example.dll",
  "capabilities":["example.feature"]
}
```

DLL 导出 CreatePlugin，返回实现 RolePlugin.h 中 IRolePlugin 的实例。使用同一
编译器、C++运行库、接口头和 JSON 库编译。原生插件为受信代码，不是恶意代码沙箱。
引擎 IPluginLoader 负责装载、初始化失败清理及卸载；应用 PluginRuntime 负责角色
工具、配置、事件、快照、停用与加载事务的业务约束。

清单可选 `dependencies:["widget"]`，其集合必须与原生 getDependencies 一致；启用
仍由后台核对，元数据不授予额外能力。管理页可联动启用依赖、关闭依赖时关闭相关
插件。新文件安装后重启后台以重新发现清单；已有配置可保存后热更新。

简单配置可由 `settings_ui` 声明，管理页无需为每个插件单写界面。最多32项，支持
toggle/number/select/text，使用 key、label、default 及数值 min/max/step 或选项列表。
见 rhythm/plugin.json。文字按普通文本显示，不加载插件 JavaScript；保留字段、原型
字段和疑似密钥字段不会生成普通输入。密钥继续使用单独的加密保存流程。声明式表单
只是编辑偏好，原生 bind 与应用策略仍负责类型、范围、依赖和权限。

构建会跟踪清单修改，不必为了复制新设置说明而修改/重新链接插件源码。复杂声库、
网站平台和工作区仍使用对应专用设置。停用插件保留加密快照，重启不自动重播旧声音。

bind/tick/event/shutdown 位于桌面 owner 线程。invoke 位于唯一模型工作线程，
必须线程安全、限定网络/文件预算、响应取消，不能直接从工作线程操控 HWND。
媒体、语音插件通过自己的受控线程执行工作，UI状态由 owner 更新。关闭程序先
停止/等待模型工作，再保存快照和卸载插件；不让对象、回调或线程跨越 DLL 卸载。

tools 返回 name/description/parameters 数组，parameters 使用引擎支持的 JSON
Schema 子集。名字必须有命名空间且不冲突；self/body/activity/reflection/memory/state/stage/schedule/workspace/computer/capabilities
为核心保留空间。invoke 返回 toolSuccess(result) 或 toolFailure(code,retryable)。
输出限1MiB，事件队列最多128项，异常转为有限错误码，不返回异常正文。

host 提供已授权草稿/素材根、桌面模式、emit 与宿主 browser 协调入口。ABI 2 增加 browser；旧插件须重编译，版本不符拒绝加载。snapshot/restore 只保存可恢复状态，
不恢复旧语音或旧气泡。插件快照与事件正文进入加密账本。新插件先暂存加载，失败
则回收；现有插件配置失败尝试回滚。底层原生外部副作用不具备数据库原子回滚。
启动加载失败会关闭该批插件并保留核心与 Dashboard，便于修正。

runtime.paused 事件用于停止朗读、暂停电视/角色游走及天气刷新；恢复不会擅自重播
历史语音或电影。当前四个插件可作为实现参考。桌面角色的 showInTaskSwitcher 为
可选可访问性设置，默认不加入任务切换列表。

widget.skin 支持 dinosaur / moonbird / lumen，widget.palette 支持 forest / mist / amber；
由用户配置，不改变角色人格。reducedMotion 或 Windows 关闭客户端区域动画时停用
呼吸、步态和拉伸。朗读嘴部由实际 speech.progress 的字符推进驱动，拖拽释放经过
landing 再回到 curious；失去鼠标捕获会恢复，不遗留 dragged 状态。暂停冻结动画
时钟，恢复不补播暂停期间的帧。全部图形为本项目的代码像素素材。

电视本地入口会解析到素材根或草稿根内，并限制文件协议和普通容器格式；网络入口仅允许
HTTP(S)及必要的内部传输协议，不允许播放列表转开本地 file/pipe/concat 路径。
这层限制由引擎 DemuxerOpenParams 的正向列表提供机制，具体范围由插件选择。

天气支持 Open-Meteo 兼容的 geocodingOrigin/forecastOrigin 覆盖（HTTPS或回环HTTP），
用于自托管与离线测试。默认官方服务，不保存/猜测真实位置。第三方API不可用时
保留已有观测时间并报告失败，不生成虚构天气。

电视结束可由 wakeOnEnd 唤醒角色；待处理指针最多8项，同插件合并，两分钟后丢弃，
后台空闲时每20秒最多处理一次。点击/拖动立即切换动画，不直接唤醒语言模型；旧版本
遗留的鼠标唤醒项会被清理。天气缓慢影响数值，语音事件不形成自我调用循环。

widget.reactionCacheEnabled 可开启应用负责的拖动短反应缓存（示例默认关闭）。启动或
空闲时准备最多六条，每条最多40字，受共享模型预算、超时、暂停与前台交谈优先级控制。
已配置的审核连接在后台批量审批；手势当下采用 cache_only，不等待审核网络请求。
speech.prepare 是内部事件，TTS 静默预合成 PCM 后返回 speech.prepared；不向模型开放
伪造准备回执的工具。消费使用 audio_cache_id + prepared_only，缺失 PCM 就失败，
不会临时合成而迟到。PCM 只在内存保存，候选/消耗记录进入加密版本账本；重启只为
未消费候选重新准备语音。实际消费前的候选不会被当成发生过的经历。

反应有效期20分钟；模型、人格版本、声音设置、活动或心情区间变化会淘汰不适配候选。
模型合法返回空反应数组时，不算生成失败，也不每分钟继续追问。后台准备使用有上限的渐进等待，空选择与失败分别计数并加密保存，正常重启延续；当前模型/声音/状态语境变化后重新准备。管理员手动补充可提前尝试。手势当下仍只消费就绪缓存，缺项直接忽略，不因此联网或排迟到语音。
默认冷却8秒、回应概率45%，可配置 reactionCooldownMs / reactionProbability。忙碌、正在输入、朗读中、无就绪条目、
超过500毫秒才处理的拖动直接忽略，不创建待播放手势。只保留最近30秒实际互动供
下一轮对话理解，不把所有鼠标反应塞进主聊天记录。

widget.position 是合并后的瞬时位置事件，每50毫秒最多一次，按所在显示器中心映射
pan[-1,1]。它只转发给插件，不入档案或事件索引、不成为记忆。小角色隐藏/卸载时
active=false 使语音居中。tts.spatialAudio 可热配置关闭；speech.status 提供当前声像
及等功率左右增益。三种声音均复用 AYAudio，Mei 分段流关闭欠载时钟推进。

电视通过 AYVideoPlayback/AYAudioPlayback 复用完整 AYVideoPlayer；窗口保留最后一帧，
双缓冲绘制，不自行解码、维护第二套音视频时钟或 WinMM 音频队列。媒体协议和本地
路径授权是不同边界；openWithOptions 保留插件选择的传输限制。

bind 会在创建后台工作前检查已知字符串、布尔值、数字范围及无凭证代理地址；
错误配置拒绝加载/重配，不把类型错误留给媒体、语音或鼠标回调线程处理。

2026-10-27：启动故障按插件隔离。缺少凭据、错误设置、损坏快照或缺失库只停用本次失败实例及声明依赖它的插件，其他独立工具继续可用；原配置和存档保留，管理页显示每项原因。启动返回plugin_configuration_partial表示存在此类缺项。运行中保存配置仍为原子事务，失败不替换当前可用实例。

快照分为持久化snapshots与实际运行liveSnapshots。关闭的插件保留存档，但其旧姿态、物件或播放状态不再进入本次身体与活动上下文。手动关闭、启动失败以及依赖失效不会被模型当作仍在运行。

口袋九盏灯pocket是可选、默认关闭的工具插件，无额外桌面窗口。角色可以开始、观察、按格子、放下；棋盘、步数、版本与胜负由程序维护，不能用模型参数直接设定。每局最多12至64步，新局通过合法规则生成，能解开也允许试错或暂时放下。每个进程的五分钟活动时间内最多新建四局，不会因失败提高依赖或强迫用户参与。进度沿原加密插件状态保存，真实解开/放下可成为后续经历；没有自动发言。缓存活动支持puzzle_start和带真实棋盘身份/版本的puzzle_press，前台输入会丢弃未做的后续动作。

创作角0.2：atelier.append以实际作品ID及expected_revision续写draft，不覆盖原文/标题；最多增加400字，合计3000字，stage可保持draft或完成finished。已完成或搁置的作品不能被缓存续写自动重开。快照最多附两件draft的600字节实际末尾节选，带tail_is_excerpt标记；它们属于创作材料，不是经历或指令。队列creative_continue前后两次检查版本，失败保留原文件，关闭插件保留草稿。

创作角0.3增加缓存occupied_slots/can_create，容量包括不可读取的已有文件，不把损坏文件当成空位。错误类型的外部version字段也只导致该文件不可用，不中断作品列表或其他插件。缓存活动根据实际空位和可见草稿提供新建/续写种类；查看与版本编辑接口仍可使用。

阅读角reading（默认关闭）提供reading.search和reading.open：角色可以自己查感兴趣的百科话题，读取实际导言摘要。默认支持中/英/日维基百科，可由操作者配置兼容服务origin；模型只能传查询词与条目key，不能改服务器、传任意网址或授权头。请求词与key作URL编码，TLS和禁用重定向沿用引擎HttpClient。自定义服务不冒充Wikipedia，实际语言与请求语言分别记录。

只返回最多五个搜索节选，或最多6000 UTF-8字节的纯文本摘要；返回scope、原始读取时间、来源链接及实际有提供的页面版本，标明不是全文阅读。HTML和缩略图链接不加载/执行，资料不作为程序指令。结果由应用记录到加密观察档案，记忆仍须走原审批流程。插件本身不会自动联网或发消息；关闭后工具从角色清单移除。最近阅读快照保留三条标题/来源元数据、最新搜索的标题/key以及一段有界的实际导言节选。

联网有单独的每小时请求上限（默认60，可设6至1200），与模型额度不同；包括失败的实际HTTP尝试。重复请求使用最多八项、五分钟的内存缓存，缓存保持原读取时间。联网额度窗口随插件快照保存，正常重启延续。没有后台无限重试，暂停/取消可中断请求。

接口依据：[MediaWiki REST搜索](https://www.mediawiki.org/wiki/API:REST_API/Reference#Search_pages)、[Page Content Service导言摘要](https://www.mediawiki.org/wiki/Page_Content_Service#JSON_endpoints)。2026-10-27对英文搜索和摘要各做一次公开查询，均取得真实结构；中文站点是否可达取决于用户网络，不伪装离线内容。

阅读角0.3补充正文源文本分段：`reading.open {key, language, detail:"source", offset:0, length:2400}`，长度256–6000 UTF-8字节；默认仍为导言。调用 [MediaWiki Core REST页面源文本接口](https://www.mediawiki.org/wiki/API:REST_API/Reference#Get_page_source)，仅接受wikitext/text，不执行其中标记、脚本或指令。源响应最多2MiB，内存缓存最多保留1MiB文字，实际送给模型及写入观察档案的只有当前片段。`offset/next_offset/total_bytes/eof/source_truncated`区分范围，UTF-8边界对齐；EOF也不代表读完渲染网页或看见图片。分页复用五分钟原缓存，不为每页另行联网。条目导言和正文片段使用同一reading_identity，避免翻页被算成多个独立经历。最新快照和后续历史检索保留实际范围；自主队列可从最新搜索或实际已读条目接续，仍受开关、预算和取消限制。

## DeepSeek 峰谷价格插件

`deepseek-pricing` 是后台策略插件，没有角色可调用的工具，不增加角色工具目录或任何模型请求。启动后异步 GET [DeepSeek 官方人民币价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，默认直连、每六小时刷新。可单独选择系统代理或 HTTP 代理。管理页“模型连接”显示当前报价（CNY/百万 token）、缓存命中/未命中输入与输出价格、源更新时间、下一时段、当前生效限制；“可选插件”提供启用、自动/手动模式和参数。手动刷新至少间隔一分钟。

价格和时间区间从官方页面解析，读取模型列与六行价目，校验币种、标签、数值和时间范围；不执行网页脚本或从页面读取任何操作指令。默认仅适用于 `https://api.deepseek.com` 连接，第三方同名模型不冒用官方计价。旧 Flash 名称只有官方页明确列为别名时映射。刷新不带 API Key，不访问账单或个人账户。

当前官方规则为北京时间工作日 09:00–12:00、14:00–18:00 高峰，周末及中国法定节假日全天谷时。实际时间窗口随重新获取的官方段落更新。中国节假日按[国务院2026年通知的政府转载](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)打包全年放假范围；调休上班的周六/日仍谷时。未来年份日历未覆盖时，工作日潜在峰段标为未知，不凭星期数猜测；需更新插件日历。固定 UTC+8 计算，不依赖电脑显示时区。

模式：

- `auto`：确认是峰段时叠加节省策略，谷段恢复用户原配置。
- `force-economy`：手动固定节省，不依赖抓取成功。
- `force-normal` 或 `off`：恢复用户原配置；保留价格显示。
- 插件 `enabled=false`：停止采集并移除整个策略覆盖。

默认峰段将历史/审核历史收紧至节省档，审核最多尝试一次，结构修复最多一次；只读查询与无对白候选省去额外语义审核。已有明确查询/静默审核设置、QQ严密模式继续优先。独立审核已启用时，最终对白与所有写入操作仍需审核；不会自动启用原本关闭的审核。工具阶段上限取用户设置与 `peakMaxToolRounds` 的较小值（默认3，含结束阶段），审核改写上限取用户设置与 `peakMaxRewrites` 的较小值（默认1）。`deferPrefetch` 默认暂缓新的自主活动和拖动反应批次预生成，已缓存反应和已执行操作继续有效。

策略在交谈开始固定，下一轮重新计算；桌面与QQ使用同一份报价策略，连续状态、原始记忆、工作区和权限不受影响。覆盖不写入 `contextControl`、`maxToolRounds`、`review` 等原配置，关闭/谷段恢复用户自定义值。每轮追踪保存 `pricing_policy`，包括当时数据来源、时段和实际限制。

抓取失败保留仍在有效期内的缓存（默认48小时，可配1–168小时），过期、系统时钟早于抓取时间、未知模型、价格页结构/规则变化时自动覆盖停止，显示具体原因。价格是当前公开报价，实际跨时段请求计费以服务商账单为准。缓存随已有加密插件快照持久保存。

开发验证：`Hibernation_UnitTests` 覆盖价目解析、边界、周末/节假日/跨年、过期和精确恢复；`Hibernation_Pricing` 使用本地模拟模型及页面验证真实进程中的策略覆盖、最终审核保留、轮数限制、手动切换与故障恢复。配置中的 `fixtureOrigin` 仅接受127.0.0.1测试服务器，状态明确标为模拟，模拟报价不会作用于真实DeepSeek连接或恢复为官方缓存。
